# 搜索居中与原生窗口 · v0.4.26

状态：独立分支候选，未合main、未推送或发布。分支 `codex/game-category-ngplus-20261025`。

## 最新反馈与实现

所有者撤回0.4.25自绘圆形窗口按钮，要求搜索居中、附近区域能够显示内容。

- 恢复原有Windows透明 `titleBarOverlay` 与系统窗口按钮；移除自绘组件、样式及专用窗口控制IPC。透明拖动安全区继续存在，窗口没有白色标题栏。
- 搜索胶囊相对作品内容区居中。header透明、无渐隐伪元素，也不遮罩滚动区；搜索本身保留原液态玻璃。
- header与滚动区域重叠，首屏通过可滚走的空白留位，滚动后内容可自然进入搜索左右及下方。header空白不拦截点击，搜索胶囊正常输入、清除与聚焦。
- 保留前批全部分类、Bento、卡片反光、列表印象、磨砂面板、回收站往返与设置导出。
- 后续同版本追加：游戏正常库的标签筛选标题行提供“＋ 新增标签”，折叠后仍可见。直接打开并聚焦前置创建表单，复用原有分组/选作品/预览/保存流程；原整理标签入口不变。回收站不提供创建入口，加载失败禁用。新增的`create`只是弹窗内存模式，不是收藏字段。
- 无领域数据、持久化结构、存储键、自动迁移变化。所有测试仅使用合成库/临时目录，原qiyu-desktop及真实收藏不操作。
