# v0.4.32 · 书籍紧凑控件与批量收录接力

- 分支：codex/books-filters-v0432；基线 40f8406（0.4.31）。原工作区的 16 处未提交修改未触碰。
- 需求：分类框贴合六个按钮、书籍排序统一圆角、七维筛选少占空间，以及批量导入书籍／书目清单。
- 实现：BookFacetPopover 锚定按钮并经 portal 悬浮，按维度导航／搜索候选，同维 OR、跨维 AND 不变；取消／筛选／排序无收藏写入。
- 导入复用 SteamLibraryImport、previewSteamImport、createSteamImportItems 与控制器 importBatch。TXT、CSV、TSV、书籍数组与 books 包装映射到既有清单模型；qiyu.batch.v1 明确板块不变。无新持久化字段／键，schemaVersion 1。
- 表格适配只认有书名表头的资料；支持双引号转义与多行简介、UTF-8 BOM、物理行号。普通逗号书名不误当表格。未映射列提示后忽略；不推断来源阅读历史。
- 豆瓣图书链接规范化成既有 externalIds，用现有编号／保守同名规则去重。未知资料不生成、空评分不变成零。批量追加保存前保留原库备份，失败保留预览。
- 书籍入口默认 book，新书可统一想读／在读／已读（日期未知）／闲置／弃读；已读不伪造具体完成日期或普通日志。混合 manifest 按每件实际类别设置初态，书籍选择不污染游戏。
- 只读审查修复：普通英文逗号书名误判、单列表头被导入、裸数组作者／平铺出版资料静默丢失；均有回归。

## 边界与下一步

这是离线书目导入，不是豆瓣／微信读书账号连接；无真实网络抓取。ISBN 暂不增加新的去重规则。导入后可在既有书单编辑中归入主题书单，文件不自动生成书单／阅读历史。下一步需单独设计书名候选匹配、来源字段映射与批量资料补全，不能未经预览覆盖用户内容。

未合 main、未推送／发布。回退源码可撤销本批提交；已有收藏无需迁移。若回退到更早程序，先导出新版完整备份，并用升级前备份副本验收，避免旧程序交替编辑同一库。
