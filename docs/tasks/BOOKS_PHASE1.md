## 可独立领取的任务

### BOOK-01 · 交互原型（READY，仅合成数据）

- 同一书籍页切换计划/记录，一次只显示一面；不是分屏仪表板。
- 至少演示：在读置顶、待读排序、补录已读/未知日期、一句感想与长读后感、已读作品新增重读计划且旧感想保留。
- 书籍页加入按每日阅读分钟数着色的热力表合成预览；演示同一天多书、日期详情及未知时长，不把未来计划算作阅读。
- 书籍基础资料与个人感受分区；专业书、文学、网文为属性/筛选，不复刻游戏通关状态。
- 范围：独立 design 原型，不修改正式 App/共享状态，不接真实网络或个人库。
- 验收：同一书目两面分别展示正确内容且未复制；桌面/窄窗截图；键盘切换、无日期登记、取消编辑和失败草稿可演示。原型通过不等于生产布局获准。

### BOOK-02 · 来源契约与读取可行性（READY，只读研究与隔离验证）

- 对照官方文档与现有豆瓣解析，逐字段记录基本资料、个人评分/书评、阅读状态/日期/进度的来源及缺失值；另外核实是否提供日级阅读时长、时区及明细编号，不能用累计时长冒充日级明细。
- 豆瓣公共资料可做少量只读验证；微信读书先确认官方 Agent 路径与桌面应用接入方式，再列需要账号实测的部分。
- 真实个人账号验证需要用户在本机连接有效凭据；不要求把凭据发进聊天，也不写入 Git、样例、截图或普通日志。尚未连接时完成合成契约/回退测试，真实项如实标未验证。
- 不把别人评论导入成用户读后感；不把书架当全部阅读史；不调用发表、修改、删除类接口。
- 验收：字段矩阵、匿名合成夹具、失败/缺字段/取消/来源失效结果、实际请求与文档推断的区别；不改变正式保存模型。

### BOOK-03 · 数据与兼容方案（READY，先提案）

- 方案需区分书目/版本、当前计划、历史阅读轮次、个人感想、来源元数据与来源个人评价；与 CAL-02 共同约定阅读时长记录的身份、日期及聚合契约，不能各自建立平行写入链。
- 完成新来源编号/去重/回收排除、批量导入、评分原始刻度、未知日期、旧库只读回退、备份恢复与旧版共存矩阵。
- 旧 status/experienceEntries 原值保留；未知字段及其他媒体不被规范化。启动不自动补写；不可逆转换不实施。
- 验收：至少覆盖同书重读、两来源同版、同名不同译本、旧书籍无日期、重复导入、来源个人书评多条/修订、0 与未评分、取消/失败零写入的输入输出示例。
- 正式字段、存储键及评分转换在方案确认前不落地。仅提供方案和可执行验收说明。

### BOOK-04 · 基础资料收录（WAITING：依赖 BOOK-02/03）

- 批准后复用既有候选预览、去重、repository、修订与备份链；扩展译者/出版社/简介等资料，按已确认方式支持豆瓣/微信读书。
- 验收：仅确认后保存；两来源关联不重复收录；歧义版本待确认；已有个人字段与人工资料不被静默覆盖；失败仍可手动收录。

### BOOK-05 · 计划/阅读记录与个人评价导入（WAITING：依赖 BOOK-01/03/04）

- 接入经审阅的单面切换、在读置顶、重读计划和逐次感想；接入经验证可取得的个人状态/评分/书评。
- 验收：库视图、详情、快捷/批量入口语义一致；重复导入幂等；来源刷新冲突先预览；保留其他媒体与旧库。
- 完成领域单测、类型检查/构建、隔离持久化重启、导入失败回归、桌面/窄窗截图；真实账号与 mock 的验收分别记录。

### BOOK-06 · 阅读热力表（WAITING：依赖 BOOK-01/02/03、CAL-02 约定）

- 在书籍页显示年度日级热力表，以实际记录的每日阅读分钟数决定色阶；点击某天查看书目和时长，并能补录/修正。
- 数据落地依赖已批准的阅读记录模型与来源契约；全局日历页面尚未完工也不阻止热力表在同一数据契约下独立实现，不另存一套重复记录。
- 验收：同一天多本书时长正确相加；重复来源/手工关联不重复计时；缺时长不算零分钟；累计时长不能均摊；跨日、补录、改日期、移除记录、未来计划、月精度记录及闰日有明确结果。键盘和窄窗可读，颜色有文字说明。

BOOK-01/02/03 可分别在独立分支推进；BOOK-04/05/06 在相应方案/原型确认前不可擅自开始正式接入。共享 types、catalog、IPC、repository 各保持唯一写入者，按现有 WORKFLOW 集成。并行写入任务最多两条；CAL-02 与 BOOK-03 的共享部分由同一负责人协调。
