# v0.4.32 · 游戏卡片与评分接力

- 分支 codex/books-filters-v0432。承接本批书籍控件与导入，不修改原工作区、main 或真实用户目录。
- 右键评分复用 InlineScoreControl，增加 deferUntilDismiss 和整菜单 commitScope；滚轮／停顿／内部焦点变化只改草稿。所有正常离开路径先结算滚轮、保存最终分数，再关闭菜单和重排；详情仍使用原 200ms 自动保存。
- 清除评分同样延后。失败不会隐式重试；保留草稿、原菜单、重试和撤销。覆盖另卡右键、键盘菜单、横向缩窗。Escape 原生捕获防止保存移除当前焦点元素后丢失关闭事件。
- 分类与优先级等明确动作先提交待定分数，再走原 action；不新建状态或评分体系，不改分段／手动排序领域规则。
- 卡片视图底部仅名称、时长、数字评分；历史字母保留并标明历史，不换算。列表的印象布局及详情资料保持。
- 二级筛选复用已有 --play-state-color，包括悬停／选中，避免全局主题按钮样式覆盖；五种颜色与封面边框一致。
- 卡面偏好继续 qiyu.cover-material.v1，新增可选开关／模式／统一材质／区间数组。旧强度、滤镜、速度、切面和未知扩展保留；读取不写回。共享缓存订阅同时更新 memo 卡片与 WebGL；关闭立即停止反光但不影响倾斜。
- 原默认映射原样保留。统一模式作用所有游戏（含未评分），区间模式只匹配可评分分类的真实数字评分；0有效、缺口／未知原图，0.1精度、含上下界、禁止重叠、最多20区间。修改区间先预览输入，应用才生效。
- 没有收藏字段／schema迁移，外观不进收藏备份；本机偏好需在本机设置，旧程序会忽略新增外观规则。

## 限制与回退
