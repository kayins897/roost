# 书籍与影视批量收录 v0.4.36

## 基线与边界

`codex/batch-intake-v0436` 从 `c58c53f`（0.4.35）建立独立工作树；原 `qiyu-desktop` 的历史未提交修改未触碰。所有者同意先补书籍／影视批量导入与真实使用流程检查，之后再完善回顾；本轮不做字体、整页视觉、分类模型或数据库迁移，不合 main、不推送、不发布。

## 实现

- 复用既有 `SteamLibraryImport` 和控制器 `importBatch`。CSV 语法由书籍／影视共用解析器，字段映射与校验各自独立。影视表头覆盖片名、导演、类型、年份、片长／集数、公开／个人评分、观看来源、标签等；JSON 支持平铺资料，明确类型保留。
- 每条书籍／影视预览有就地修正表单。应用只修改未保存草稿，即时重算重复、计数和可选项。最终导入仍对 `snapshotRef.current` 再次去重；失败保留草稿与选择。
- 有效 ISBN 校验后仅建立临时去重身份（含10／13位等价），不改写书号原文。无效旧书号继续保存但不以此认定同一本书；原有保守同名规则不变。
- 豆瓣图书的已有 `bookDetails` 资料链补齐；原有单件合并只补空、保留零值、个人记录及未知扩展，不从公开资料建立阅读渠道。
- 预览读取复用既有类型化 `lookupMetadata` 契约与主进程来源白名单，不增加网络端点或账号能力。仅请求确切匹配的图书／影视 subject URL，串行、两件之间间隔800ms，任一失败暂停。仅补草稿空缺；来源编号／板块不符拒绝应用。停止等待当前请求结束，晚返回不会污染预览；卸载同样丢弃返回。
- 影视默认类型延后到最终创建，避免默认电影阻挡来源明确返回番剧；清单明确类型不变。不会以片长、集数或公开评分推断个人经历。

## 验证与交接

实际最终验证结果以交付目录验收报告为准；不把作者单测、源码测试、成品测试和真实网络混为一谈。专项入口 `node scripts/verify-batch-intake.cjs [成品EXE绝对路径]` 使用真实隔离 Electron 与合成主进程来源响应；覆盖预览修正、来源失败／重试／停止、取消／晚返回、修订冲突、类型、ISBN、重复追加和重启。手动步骤见 [0.4.36验收](../release/验收步骤-0.4.36.md)。

测试与截图仅用隔离临时目录，不触碰 `%APPDATA%\QIYU`。本轮不进行真实账号或真实书库自动导入；来源实时可用性须单独人工确认。没有新持久化字段／存储键，schemaVersion仍为1；同schema不代表任意旧版本可安全交替写库。启用前导出完整备份；回退保留原程序、升级前备份及新版完整导出。
