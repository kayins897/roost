# 分类与列表优化候选 · 2026-10-26

完整解压后双击“启动演示.cmd”，窗口顶部应有“演示数据”提示。此入口使用独立临时目录，与正式收藏分开；再次打开保留修改。不要用正常 EXE 做隔离演示。

1. Dock 文件夹加号是“收录作品”，打开后选择手动、检索或批量；标签整理在此面板内。主工具栏不再重复三个入口。
2. 选择新作开荒/已体验；双选显示全部，不能全部取消。已体验下有游玩中、未完待续、新游戏+、收官完结、暂时搁置与未分类。
3. 右键“星海旅人”切换游玩中，再改新游戏+。游玩中可以定优先级，新游戏+可以分别定优先级和通关评级。切换分类不清除历史等级、时长、次数。
4. 列表视图的前端显示等级和封面，大块横向区域是印象。直接输入，Enter/离开保存，Esc取消，最多80字；测评不受影响。多选时印象只读。
5. 打开详情：封面完整、统计分清未记录/0、长文默认折叠；体验分类原地展开，无通关进度控件。普通体验日志不会增加完成次数。
6. 比较“银幕之外”(B)、“金色余晖”(A)、“蓝湾回声”(S)、“星海旅人”(SS)、“潮汐协议”(SSS)封面悬停：烫银/烫金/蓝银闪箔/彩带镭射/全谱多彩。无网点、网格。系统减少动态效果时关闭反光。
7. Dock 垃圾桶打开回收站，可恢复作品；旧隐藏作品在“数据与设置 → 数据与备份 → 已隐藏作品”找回。没有自动删除/取消隐藏。
8. 改一句印象和优先级，关闭后从同一演示入口重开，核对修改仍在。

正常使用前先在旧版导出备份并自行退出旧版。此候选新增 playing 二级枚举，前批同为0.4.24的候选可能拒绝读取；不要混用旧程序保存新库，回退使用升级前备份，并保留新版完整导出。启动无迁移或补写；普通完成日志与次数及通关事实相互独立。
