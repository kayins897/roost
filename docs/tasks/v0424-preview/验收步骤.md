# 栖域 0.4.24 五分钟验收

完整解压后双击 **启动演示.cmd**。横幅显示“演示数据 · v0.4.24”。演示使用随机独立临时目录，与正式收藏无关，可同时打开。不要删除旁边的 qiyu-demo-profile.json；下次仍从同一入口打开。若临时目录被系统清理，入口会明确报错，可保留旧目录记录并重新解压到新文件夹新建演示。

1. 点击“全部游戏”，打开“星海旅人”：46小时、游玩中、已通关、SS评级。将当前关系改为计划游玩，通关和评级仍在。右键也能在同一菜单设置两个维度及优先级/评级。
2. 打开“远界编年史”：60小时、明确未通关。改为暂时搁置，时长保留；回库选择“暂时搁置”与“明确未通关”组合能找回它。
3. 打开“无尽回廊”：进度不适用，可设个人评级；累计未记录不会显示0。
4. 打开“潮汐协议”：累计3次。记录一次完成，明确选择“同步+1”，保存后为4，再撤销回3。事件和进度只撤销本次造成的变化。
5. 打开“机械花园”：记录一次，实际日期只填2023；累计保持未记录，保存后仍未知，日期不会补月份。可编辑清空日期/备注，删除默认不扣累计。需要修正累计时明确填写。
6. 多选“雪原信标”“林中隙光”“灰烬之城”“双星彼岸”作快捷优先级；用搜索隐藏其中一件，工具栏仍提示结果外选择。已通关且计划游玩的集合可切换设置优先级或个人评级。
7. 在已通关视图同级组内用上移/下移或拖动排列（包括当前关系不同的作品）；分组可以折叠。选择其他排序时不写手动顺序。
8. 关闭演示，再双击**同一启动演示.cmd**，修改仍在。正常“栖域.exe”沿用正式库，如旧版仍在运行会唤醒旧版；请自行备份和退出旧版后再正式使用。
