# 栖域 0.4.24-nightly.20261025 · 夜间验收预览（非正式发布）

这是 2026-10-25 夜间开发候选的**本地验收预览包**，供所有者试用，不是正式发行版；未合入 main、未上传 GitHub。数据格式与 0.4.23 完全一致（schemaVersion 1），可直接读取现有收藏。

## 本包包含什么

1. **右键菜单内联等级（含修复）**：右键待体验/已通关游戏直接在菜单里选 SSS–C 或未设置；修掉了「待体验计划滚到底改已通关时菜单被误关」和「其他状态保存失败菜单先关」两个问题。
2. **标签跨组移动**：标签管理里每个游戏标签多了「移动到」分组选择，确认框会显示影响多少件作品。
3. **多选快捷定级**：多选全部待体验游戏时，底部工具栏直接出现「统一待体验优先级」（全部已通关则出现「统一通关评级」），选档后显示将更新几款，点应用即保存。
4. **离线清单导入预览**：批量收录预览新增 全部/可新增/库中重复/清单内重复/已移除跳过 五类筛选（带计数）、「全选当前结果」（支持半选）、以及被搜索/筛选隐藏的已选数量提示。
5. **多选补齐 Steam 资料**（仅桌面）：多选带确切 Steam AppID 的游戏 → 工具栏「补齐 Steam 资料」→ 只补缺失的封面/开发商/年份/原名，已填内容不会被覆盖，不读库存、不改时长。

## 两种试用方式

**A. 直接用现有收藏**：解压后双击「栖域.exe」即可，行为与 0.4.23 相同（读同一份 %APPDATA%\QIYU 收藏）。建议先在「数据与设置」导出一份备份再体验。

**B. 隔离演示库（不动真实收藏）**：本目录有 `演示收藏-demo-library.json`。在 PowerShell 中：

```powershell
$env:QIYU_TEST_DATA_DIR = "$env:TEMP\qiyu-nightly-demo"
New-Item -ItemType Directory -Force "$env:TEMP\qiyu-nightly-demo" | Out-Null
Copy-Item .\演示收藏-demo-library.json "$env:TEMP\qiyu-nightly-demo\library.json" -Force
.\win-unpacked\栖域.exe
```

（关闭窗口后该临时目录可整目录删除，与真实收藏无关。）

## 5～10 分钟快速验收步骤

1. 右键「星海旅人」（待体验）→ 菜单出现「待体验优先级」一行 → 点 S 保存 → 重开右键确认高亮在 S。
2. 右键「林中隙光」→ 点「已通关」→ 菜单不关，就地出现「通关评级」→ 点 SS。
3. 多选「星海旅人 + 林中隙光 + 机械花园 + 雪原信标」→ 底部出现「统一待体验优先级」→ 选 SSS → 显示将更新 4 款 → 应用。
4. 标签管理（右侧 Dock「标签」）→ 玩法组「肉鸽」行 → 「移动到」选题材 → 确认框显示影响 1 件 → 确认。
5. 批量收录 → 粘贴几行游戏名（可含重复）→ 生成预览 → 顶部五类筛选与计数、「全选当前结果」半选、搜索后「另有 N 件已选被隐藏」提示。
6. 多选「机械花园 + 雪原信标」→「补齐 Steam 资料」→ 跳过说明与预览将补字段 → 确认写入（需要联网读 Steam 公开商店资料；失败与取消都不会写入）。
7. 重启应用 → 以上修改全部保留。
