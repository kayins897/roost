## 本轮实现

- 多选操作栏、展开筛选、排序及多选下拉统一磨砂。底色有可读性下限，选项使用实色高亮与勾选；与 Dock/搜索的液态玻璃分层。
- 收录、设置弹窗统一磨砂。收录三入口、设置卡片与悬浮分类导航使用协调的透明底色，设置搜索仅保留外层圆角焦点框。
- 操作毛玻璃开关、减少透明度与不支持 backdrop-filter 时降为实底。保留导航玻璃的独立设置。
- 回收站 Dock 再次点击返回作品库，工具提示与按下态同步；保留原返回按钮、隐藏作品恢复入口及草稿保护，不写收藏。
- 列表印象移除上下常驻备注；仍保留读屏名称、80字校验和保存失败提示。
- 本地保存标识移至左下版本旁；导出入口收纳于“数据与设置 → 数据与备份”。
- 滚动时在搜索下方使用独立柔化层。没有给整个滚动区加 mask，以免改变内部玻璃的背景采样根。
- Windows 顶部三个独立圆形玻璃按钮，无外围胶囊。悬停/聚焦明显高亮，关闭为红色反馈。原生拖动、标题区双击及窗口边缘能力保留；其他平台仍用原生标题栏。
- 包版本与锁文件同步为0.4.25，界面版本来自包元数据。本地文件夹用“界面与分类优化-v0.4.25”，ZIP仅提供免安装版。

前一批游戏分类、双等级、Bento、封面反光、列表编辑、收录整合见[分类与列表交接](LIBRARY_REFINEMENT_2026-10-26.md)，全部保留，不重新立项。
