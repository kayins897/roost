# v0.4.28 · 详情与卡面正式接入

所有者已批准将 `design/detail-gallery`、`design/holo-card-reference` 两个独立示例接入应用；本分支为本地验收候选，不合 main、不发布。原目录和其它分支未提交成果保留。

## 规则与接口

- 评分 0–10，支持 0.1 分；9.5–10 多彩，9.0–9.4 镭射，8.0–8.9 闪箔，低于 8 为原图。默认纹理/滤镜/速度均 100%，三角切面开启。材质公式从独立示例移入；不同原图会产生不同视觉结果。
- 新增可选 `personalScore`，旧 `personalGrade` 不自动换算或清除；有数值时数值优先。历史字母保留独立标识；优先级仍为 SSS/SS/S/A/B/C。
- 数值评分采用整数、小数两个独立滚轮，支持滚轮/拖动/点选/键盘；10分锁定小数。所有入口共用`ScorePicker`，只改变草稿，由原入口提交保存；未交互不把未评分变为0。
- 新增可选 `lastPlayedAt`，未知不伪造，本轮由用户手动记录，尚未接入 Steam 最后运行时间同步。次数、通关事实、日志不混用。
- 新增可选 `screenshots`、`screenshotCoverId`；图片元数据含内容散列、basename、尺寸、说明与加入时间。不保存来源绝对路径，不将截图原图塞入收藏 JSON。
- 截图原图复制保存于用户数据目录 `screenshots`，内容寻址去重，并生成缩略图；缩略图缺失回退原图。单张最大40MB，每次最多30张，每游戏1000张。移出相册只删引用，原图暂不清理，以保护 previous/daily 备份。
- `.roost` 为自定义二进制完整备份：版本头、有界 JSON 目录和原图字节，逐图 SHA-256 校验。最大4GB。导出缺图失败；恢复预览不改收藏，确认后先安装图片、最后走原仓储的修订检查/原子保存及恢复前备份。旧 JSON 仍可恢复，跨设备带截图必须用完整备份。
- 布局与卡面材质是独立偏好，分别存 `qiyu.detail-layout.v1` 与 `qiyu.cover-material.v1`，不混入收藏；全局详情模板可改大小、位置、显隐、字段、颜色和截图1/4/9布局。隐藏/重置卡片不删除收藏内容。
- 库中只为悬停封面维护一个共享 WebGL 上下文；滚动/离开/窗口隐藏停帧，保留原图回退；减少动态设置停止自动流动。库卡片倾斜保留。

## 兼容与回退

`schemaVersion: 1` 不变，启动纯读取不补字段；用户明确编辑才新增字段。旧版可能保留未知字段，但不能展示截图/数值评分，不应交替编辑同一库。回退用升级前 JSON 副本；保留新版完整备份与截图目录。不要用旧版 JSON 覆盖截图原图。测试仅隔离合成资料。

## 验证入口

`npm test`、`npm run desktop:build`、`node scripts/verify-bento-materials.cjs`；成品在同专项后附 EXE 路径。实际执行结果、截图与剩余限制在交付验收说明记录，不沿用示例检查数量。

## 剩余限制与接力边界

- 未跑历史全流程脚本；本轮以对应专项覆盖新接入路径，不沿用历史15/19阶段通过结论。
- 未测多GB备份压力、500款收藏下的GPU性能及真实网络封面。图库只为当前悬停封面创建一个共享渲染器，性能极限仍需后续实机观察。
- Switch暂用通用手柄图标与平台文字；其余已收录的平台标识使用现有来源注明的本地SVG。
- 截图资产暂不自动清理；布局/材质偏好不随完整备份迁移；最后运行时间本轮手动记录。
- 本轮不合并main、不推送、不发GitHub Release。交付只做Windows x64免安装候选，成品测试记录与来源提交放在交付报告。
