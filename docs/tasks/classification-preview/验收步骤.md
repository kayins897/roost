# 游戏分类与详情 · 隔离演示验收

这是 0.4.24 基础上的独立分支候选，未合并主分支、未正式发布。请完整解压后双击 **启动演示.cmd**，先体验随包的虚构游戏库。此入口使用独立临时目录，不读取正式收藏；重复启动保留演示修改，不重新播种。不要直接运行 EXE 来进行隔离演示。

## 本轮重点

1. 一级仅“待体验 / 已体验”：先点“已体验”使两项都选中显示全库，再取消“待体验”。两项不能同时关闭。已体验下试五个二级和未分类。
2. 右键游戏直接选择长线游玩或已放下。多选两款不同分类，底部“体验分类”可一次统一；待体验优先级继续使用 SSS–C。
3. 点击封面打开居中详情。封面完整显示；体验分类点击后原地展开；时长和完成次数并列。普通分类选择不修改时长、通关事实或完成次数。
4. “机械花园”演示主观已通关而客观尚未记录；“无尽回廊”是长线游玩、通关不适用；“潮汐协议”是可重玩且完成过多次。“留白档案”演示已体验但无二级、时长未知。
5. 编辑宽卡片中的一句话印象，展开默认折叠的长文测评。添加普通体验日志，检查完成次数不变；“记录一次完成”是另一个独立操作。
6. 缩窄窗口检查封面、统计、文字和滚动。游戏库原有悬停倾斜保留。
7. 完整退出后仍通过同一“启动演示.cmd”重启，检查刚才的分类、印象和记录保留。

## 数据兼容

新增可选 experienceStatus / experienceCategory，格式仍为 schemaVersion 1。旧数据仅在读取时推导一级，不启动重写、不猜测二级。旧分类原文保留；有歧义的旧搁置/放弃需要用户日后整理。人工分类优先于时长及同步数据。普通日志不会变成完成次数。

正式收藏尚未被本次测试访问或修改。若要用真实库验收，请先自行导出备份，再运行 EXE；旧程序不保证理解新分类，请保留升级前备份和新版完整导出，避免两版交替写同一份库。演示入口记录或演示库损坏时会停止，不会回退打开正式库。

本轮源代码结果与范围见随包“验收与兼容说明.md”。真实 Steam 网络和旧版交替写库不计为已验证。
