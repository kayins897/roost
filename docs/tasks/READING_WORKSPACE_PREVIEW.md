## 可体验内容

入口和操作步骤见 [预览 README](../../design/reading-workspace/README.md)。生成后双击 `index.html` 即可，也可通过其 `serve.cjs` 在本机 4186 端口打开。

1. 日历有年/月/周、媒体及搜索筛选、前后范围和今天。按范围列出各媒体记录/作品数及已知分钟，未来或过期计划独立显示。
2. 年度展示十二个月，月份精度记录单列而不冒充具体某日；每周以周一开始，跨月/跨年仍按七天回顾和规划。
3. 书籍计划/记录只显示一面，在读置顶，待读排序；同书重读不复制书目，历史感想按轮保留。
4. 资料和个人感想分开，短印象与长文分开；补录支持未知/月/日日期。普通阅读记录不自动当作读完，读完不额外增加分钟。
5. 年度阅读热力表与日历使用同一合成活动数据；同日多次/多书可加，明确 0、未知分钟及完全未记录分别展示。窄窗默认露出近期，键盘只有一个热力格入口，可用方向键选日。
6. 录入、修正、删除分钟同步影响两种视图；取消/模拟失败不更新状态，重试保留草稿。取消计划不删历史，删除日志不删作品。

全部是合成示例，包括书封、感想和阅读时长；固定演示今天为 2026-10-27。仅内存，刷新即复位；不是正式数据实现或已完成来源同步。
