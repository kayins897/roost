# 栖域 0.4.26（Roost）五分钟验收 · Windows x64 免安装

启动：完整解压后双击 **启动演示.cmd**。窗口标题为「栖域（演示数据）」，顶部横幅显示演示数据与本版版本号。演示使用独立临时目录与合成收藏，可与正式版并行，不会读取或写入 %APPDATA%\QIYU。请不要删除同目录的 qiyu-demo-profile.json；同一入口再次启动会保留演示中的修改。

## 1. 搜索居中与新标题区
1. 在 1440、880、390 宽度下，搜索胶囊相对内容区居中。
2. 向下滚动列表：搜索左右两侧能看到作品卡片并能正常点击；下方没有渐隐或模糊遮挡层。
3. 搜索输入、清除按钮、Dock 回顶均正常；首屏保留搜索留位，滚动后内容自然进入搜索下方。

## 2. 原生窗口控件
1. 右上角是 Windows 系统最小化/最大化/关闭，悬停显示系统提示，不是自绘圆形按钮，也没有白色标题栏。
2. 双击标题区空白可最大化/还原；拖动标题区空白可移动窗口。
3. 打开设置与任意弹窗，标题区不遮挡内容，窗口按钮仍可点击。

## 3. 标签快捷新增（本轮重点）
1. 进入「游戏 → 全部游戏」，标签筛选标题行右侧只有一个小加号；没有常驻「新增标签」文字或底框。悬停提示与读屏名称都是「新增标签」。
2. 点击加号后弹出「新增标签」表单，光标已落在「新标签」输入框；选择分组（玩法/题材/游玩场景/其他），输入名称，例如「周末合作」。
3. 点「选择要添加的作品」进入选择模式，勾选 1–2 件作品，再点底部确认按钮。回到列表后，新标签出现在对应分组与标签筛选里。
4. 再次打开加号后直接关闭或取消：收藏不新增任何标签，也不产生保存。
5. 回收站视图不显示加号；加载失败时加号禁用。

## 4. 详情与列表
1. 打开任意游戏详情：Bento 分块布局完整，封面反光随鼠标移动。
2. 详情里可切换新作开荒/已体验与二级状态；优先级、评级随状态联动，与 0.4.25 一致。
3. 列表视图双击或聚焦一句话印象，输入 80 字以内文本，Enter 保存、Esc 取消；超长被截断且有计数提示。

## 5. 保留能力回归
1. 设置弹窗为磨砂玻璃可开启，关闭后状态不被重置。
2. 回收站连点两次可退出，物品可恢复。
3. 保存标识在左下角可见，导出完整备份可用。

## 6. 数据与隐私
1. 演示过程不读写 %APPDATA%\QIYU；退出后正式收藏数量不变。
2. 关闭应用后检查演示目录：不应残留收藏定位记录或锁文件以外的个人数据。

## 已知限制
- 这是预发行候选，未替换稳定版标签；请保留现有稳定版以免影响日常使用。
- 本版仍在 schemaVersion 1 上扩展了二级类别 `playing` 等取值。旧版候选不认识这些取值，不要用旧版与本版交替编辑同一份收藏；升级前请用应用内导出做完整备份，并另存一份新版导出便于回退。
- 全量工作流的原生阶段已在候选程序上运行，包含网页阶段与 19 阶段历史流程的差别见仓库中的交接摘要。
- 首次启动可能触发 Windows SmartScreen；这是未签名分发包，属预期现象。

## 升级与回退
1. 升级：解压到新目录覆盖旧免安装目录前，先完整导出一次收藏。
2. 回退：保留升级前的 `%APPDATA%\QIYU` 备份目录与完整导出文件，用旧版程序打开备份副本，不要直接在同一定位目录上双向写。
