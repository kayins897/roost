# v0.4.29 · 评分与卡面优化

这是独立分支的本地免安装候选，未合 main、未上传。先解压全部文件，双击“启动演示.cmd”使用合成收藏验收，演示中的操作不影响真实收藏。

1. 打开一款新游戏+或收官完结游戏，右键通关评分卡。整数、小数仍为两个滚轮；鼠标每一格只改变一档，不再按滚动像素跳四档。方向键、点数字、拖动仍可用。10分小数锁为0，0分与未评分不同。
2. 在独立评分菜单内选值，停下约0.2秒便自动保存，没有“保存”按钮；连续快速拨动合并保存最终值。按Escape或点菜单外立即离开，也会先保存最后所选分数。重新打开确认。库卡片右键评分使用同一操作。
3. 清除评分只清除数值；旧字母评级不会被换算或删除。新增/编辑作品的完整表单仍需保存整张表单；多选统一评分仍需点击“应用评分”，避免误改多款作品。
4. 在游戏库悬停比较8.0–8.9闪箔、9.0–9.4镭射、9.5–10多彩。闪箔改为局部银亮曲面，多彩保留封面原色和细节，只在局部叠彩膜；镭射公式不变。历史A评级的烫金改为局部暖金高光。静态截图不能代替鼠标移动时的体验，请分别在明暗封面上尝试。
5. 设置→卡面材质仍可调纹理、底色滤镜、速度；默认100%、三角切面开启。调到0可比较原图。不满意可关闭材质，游戏资料、评分不受影响。
6. 重新启动演示，确认评分、个人文字与截图仍在；0.4.28的Bento、托管相册、完整备份保持可用。备份方式见上一版说明，含截图请使用单文件`.roost`完整备份。

自动保存失败会在原菜单保留所选分数，显示“重试”和“撤销修改”；普通外点不会自动重复尝试。现有修订冲突保护及原子备份保持不变。极大的内嵌封面收藏仍受现行整库同步保存速度限制；本版只合并快速拨动，不更换存储方案。

正式使用前在旧版导出完整备份，再退出旧版、启动本版。收藏仍为schemaVersion 1，本轮没有新增数据字段、存储键或迁移，不会启动时改写。回退时保留升级前备份与新版完整导出，不要用旧版反复编辑同一份新版收藏。书籍、小说与影视不在本轮修改范围。
