# v0.4.41 · 书籍、影视详情与搜索收录

这是继 v0.4.36 后的 Windows x64 免安装预发行更新。

- **书籍详情**沿用游戏和影视的 Bento 布局。封面与个人评分分别成卡，豆瓣评分归入来源卡。阅读安排和「记录阅读」位于书名旁，出版资料、简介与感想可逐卡编辑。
- **影视详情**将海报、个人评分、片长、发行、演职员、来源与简介拆成大小错落的卡片。电影多刷、剧集季集进度和观看日志仍分别记录。
- **搜索收录**可从书籍或影视页按名称搜索豆瓣，选择结果后在同一窗口继续收录。详情暂不可用时，可确认后保存搜索结果中的基本资料。搜索结果仍会检查重复。

完整解压 `Qiyu-NoInstall-0.4.41-x64.zip`。可双击「启动演示.cmd」体验独立的演示收藏。正式使用前可在旧版导出完整备份，再退出旧版并启动「栖域.exe」。收藏沿用 `schemaVersion: 1`，启动时无需迁移或重新导入。

本机通过 299 项单测、桌面构建、18 项书籍成品回归和 24 项影视成品回归。用隔离收藏对照三类详情的窗口和卡片样式，并验证了 390 像素宽时书籍封面与评分仍可并排。资料检索自动化使用合成响应，实际收录受网络与来源可用性影响。

GitHub Actions 从发布标签重建免安装包。下载时使用随包发布的 `SHA256SUMS.txt` 核对散列，包内 `SOURCE.json` 可核对构建提交。
