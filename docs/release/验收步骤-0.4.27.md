# 栖域 0.4.27 · 标签整理候选验收

完整解压后先双击 **启动演示.cmd**，核对“演示数据”和 0.4.27。此入口使用合成收藏独立目录，不接触正式收藏；同一目录再次启动保留演示修改。请保留演示目录定位记录。

## 1. 选择已有标签

1. 右键任意游戏 → 编辑标签。四组输入框下面显示已有标签。
2. 点选已有标签，选中时有勾；再点可取消。同名在不同组独立。
3. 也可直接输入新标签，用顿号或逗号分隔；点保存后查看详情与筛选。
4. 修改后取消会询问是否放弃；选择放弃不保存。详情内“编辑标签”行为一致。

## 2. 新增并分配

1. 点击“标签筛选”旁加号，选分组、输入名称，点“选择要添加的作品”。
2. 底部是专用标签栏，只有标签名、选择管理、添加/移除方式和应用按钮；没有隐藏、分类、评级或垃圾桶。
3. 勾选作品，检查“添加到 N 款”的数量，点击即可应用，不再打开第二个弹窗。
4. 从“收录作品 → 整理标签”找到已有标签，点“分配作品”；可以切换到“移除标签”，只移除所选组的此标签。
5. 搜索改变后仍保留原选择，栏内提示不在当前结果中的数量。无需修改的作品不会重复写入；取消分配不改变收藏。

## 3. 常规操作与旧隐藏记录

1. 普通多选的添加/移除标签也能选择已有标签；保留原批量分类、等级及回收操作。
2. 普通作品右键、详情底部、多选栏没有“隐藏”。设置里保留历史隐藏作品查看与取消隐藏，避免旧收藏无法找回。
3. 在窄窗口下滚动四组标签，确认保存和取消按钮可达；切换板块或回收站后不残留分配栏。
4. 关闭演示后再次启动，检查已修改的标签仍存在，分类、时长、印象和测评保持。

## 范围与正式使用

- 仅本地候选，未合 main 或发布；本轮没有 Steam 商店标签自动导入功能。可行性与后续建议见更新说明和任务交接。
- schemaVersion 1，没有新字段或迁移。正式使用前在原版本设置中导出完整备份，退出原版，再启动新目录中的栖域.exe；不要让旧候选交替编辑同一份收藏。
- 自动测试覆盖合成数据，不代表已验收个人大库或所有网络来源；正式库存未用于测试。
