# v0.4.28 · 详情与卡面验收

这是独立分支的本地免安装候选，未合 main、未上传 GitHub。建议先双击“启动演示.cmd”，不改真实收藏。

1. 点击游戏封面：详情保持居中，全页彩色卡片，没有标题栏；查看独立作品资料、平台、标签、评分、印象、截图和体验足迹。长文默认折叠，完成次数默认隐藏。
2. 在“体验与足迹”中点分类就地修改；右键此卡可设置字母优先级、添加体验日志、记录一次完成。普通日志不会增加完成次数。
3. 对“新游戏+”或“收官完结”游戏右键评分卡，分别滚动整数与小数两列，设置8.5、9.2、9.8并保存；支持拖动、点数字或方向键。整数10时小数锁为0，未评分不等于0。回游戏库悬停比较闪箔、镭射、与多彩。原字母评级不自动换算。右键游戏、收录表单与批量工具栏共用滚轮评分。
4. 右键任意卡片直接编辑其内容；再进“外观与布局”改颜色和尺寸。右键封面→外观与布局→整理整体布局，可拖动/上移/下移，并管理显隐、恢复完成次数。取消只还原本次布局，不撤回之前明确保存的个人内容。
5. 右键截图卡导入 PNG/JPEG/WebP。点击图片浏览原图、设封面、填写说明。右键切换单图、四宫格、九宫格。移动或删除来源文件后重启，已复制截图仍在。移出相册不删除来源文件。
6. 右键时长卡分别试空白、0、已知时长与最后运行时间；确认未记录和0有区别。最后运行目前手动记录，不从日志和文件时间猜测。
7. 设置→卡面材质：默认三项100%、三角切面开启；降到0或关闭切面比较，恢复默认。
8. 设置→数据与备份→导出完整备份，得到一个.roost文件；在另一份隔离演示中恢复，确认收藏、评分、文字、截图均还原。恢复会明确确认替换，并保存操作前备份。

截图只支持桌面版导入；旧 JSON 不携带截图原图。上限：单张40MB、每次30张、完整备份4GB。全局布局跟随本机偏好，不属于作品资料；完整备份目前迁移收藏和图片，不迁移外观偏好。回退请保留升级前备份及新版完整备份，不用旧版反复编辑新版库。
