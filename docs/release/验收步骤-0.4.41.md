# 0.4.41 PC 书籍详情验收

完整解压后，可双击「启动演示.cmd」打开独立收藏。

1. 分别打开游戏、电影和书籍的详情，对照深色窗口、卡片间距、个人评分、感想和标签用色。缩窄窗口后检查书籍封面与评分是否仍能并排显示。
2. 打开书籍的阅读状态胶囊并切换状态。用「记录阅读」登记时长，再从读后记录补录一次读完，检查时长和读完轮次分别更新。
3. 分别右键「我的评分」「出版信息」「来源与评分」和「作品简介」，检查编辑范围。个人评分和豆瓣评分分别保存。长简介和读后感均可展开。

正式使用时可先在旧版导出备份，再退出旧版并启动新版。收藏格式沿用 schemaVersion 1，回退时可用旧版打开备份副本。
