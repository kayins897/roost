# 栖域0.4.33影视模块验收

先完整解压，运行“启动演示.cmd”，核对左下v0.4.33和顶部演示标识。演示采用合成书籍／游戏／影视，与正式收藏隔离。正式使用前先在旧版导出完整备份。

1. 点Dock影视：切换全部、想看、在看、看过、搁置、弃看；切换电影／连续剧／番剧、封面／列表，确认在看普通封面置顶。
2. 打开筛选：导演、年份、我的评分、豆瓣评分、观看来源、资料来源分别选择；点标签筛选，使用旁边＋创建和分配标签；右侧新建主题片单。
3. 点“星河之间”：修改季／集进度，确认不会增加看过轮次；记录观看0分钟或空时长，确认和45分钟片长分别显示。
4. 补录看过：日期可留空或填2026、2026-10、2026-10-28，写感想。重新安排在看，再补一次看过并取消“结束当前观看安排”，确认两次感想保留且仍在看。
5. 右键封面设置个人评分，两列滚轮逐档；菜单关闭前封面不重排。评分失败时草稿保留，用“重试”或“撤销修改”，不能期待再次点击外部自动重试。
6. 编辑一句话印象，展开长文观后感；关闭重开，确认感想保存。资料和标签用卡片右上图标编辑。
7. 多选两部影视修改观看安排；移入回收站，再点Dock垃圾桶退出，确认没有残留旧菜单。回收站可恢复或明确确认永久删除。
8. 影视“批量收录”粘贴每行一个片名，生成预览，选择初始观看安排再确认。重复项跳过。单件豆瓣链接从Dock“收录作品→检索与导入”进入，真实联网可能遇到限流。
9. 缩小窗口检查筛选、详情与列表；退出整个演示进程，再次从同一“启动演示”入口启动，确认修改读回。

本轮不含账号私有片单同步、逐集追踪、播放计时或日历正式接入。旧库启动不迁移；如要回退，保留新版完整备份和升级前副本。
