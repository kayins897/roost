# 栖域 0.4.31 · 书籍管理验收

本版将已确认的书籍独立预览接入正式应用，沿用应用背景、主题配色、Dock、搜索与磨砂控件。只提供 Windows x64 免安装候选，未自动合并 main 或上传发布。

## 安全试用

1. 完整解压后可先用「启动演示.cmd」；演示目录与真实收藏隔离。
2. 正式使用前，在旧版设置中导出 `.roost` 完整备份，然后自行退出旧版，再打开本版「栖域.exe」。
3. 左下角核对版本 0.4.31。空书架不播种预览示例，可从 Dock 收录作品或书籍页「收录书籍」添加。

## 五分钟验收

1. 切换书籍，收录一本想读书；切换全部／想读／在读／已读／闲置／弃读、封面／列表。
2. 打开详情，写一句话感想和长文读后感，补全出版社、译者、阅读来源等资料。我的评分与豆瓣评分分别填写。
3. 将书设为闲置，编辑阅读计划；保存计划理由不应自动变为想读。补录已读，日期不知道可留空；重新安排在读，再补录一次，第一轮感想仍在。
4. 添加一天阅读记录，填 0、留空、35 分钟分别检查显示；普通阅读日志不增加读完轮次。
5. 顶部热力表默认展开，可折叠；切年，选择一天，查看或编辑该日记录。只有精确日期的阅读日志进入日格。
6. 点标签筛选旁加号，建立标签并勾选书籍；筛选面板可按作者、出版社、个人评分、豆瓣评分、类型、阅读来源和资料来源组合筛选。
7. 右侧新建主题书单，填写主题并选择书籍；点书单筛选，再取消。窄窗口下书单移到书架下方。
8. 关闭本版后重新启动，核对书籍、计划、感想、日志、标签及书单。设置中导出完整备份，保留用于迁移和回退。

## 范围与兼容

- 收藏仍是 schemaVersion 1。只增加可选书籍扩展，启动不迁移、不补写旧库。
- 历史 finished 书籍只读显示已读，日期未知；paused 显示闲置。后续修改当前安排不清除旧状态、历史读后感或轮次。
- “已读”统计历史，与当前想读／在读等安排可能交叉；全部视图按书去重。
- 豆瓣链接识别沿用既有能力；微信读书／汉王是可手动记录的阅读来源，本版不声称已接通账号、笔记或设备时长。
- 热力表不推断累计时长的逐日分布，计划不计入热度；未记录与明确 0 分钟分别展示。
- 外观折叠、筛选和显示方式属于本次页面会话偏好；重新打开恢复默认，不写入收藏。
- 回退时使用升级前备份副本。旧版不理解书单与轮次，不建议新旧版轮流编辑同一数据目录。
