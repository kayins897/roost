# v0.4.36 · 游戏、阅读与影视收藏

这是继 v0.4.26 后的累计预发行更新，面向 Windows x64；只提供免安装 ZIP。

## 本次可体验

- **游戏详情与相册**：彩色 Bento 小组件、逐卡右键编辑、布局与颜色自定义；截图复制保存，支持单图／四宫格／九宫格及含原图的单文件完整备份。
- **分类、评分与规划**：新作开荒、游玩中、未完待续、新游戏+、收官完结、暂时搁置；字母游玩优先级与 0–10 个人评分分开。右键滚轮编辑先保留草稿，结束后再保存重排；评分按一分一段整理。卡面仅保留镭射／多彩，可关闭、统一材质或指定评分区间。
- **书籍**：全部／想读／在读／已读／闲置／弃读，封面与列表切换，七维资料筛选、标签、主题书单和可折叠年度阅读热力表；阅读分钟、读完轮次与感想分别记录。
- **影视**：电影／连续剧／番剧分别管理。电影使用想看／看过与多刷记录；剧集支持在看及季集进度；电影主题片单与普通标签分开。
- **批量收录**：书籍与影视支持清单、CSV／TSV、模板和预览纠错；确认前检查重复，有效 ISBN-10／13 可等价去重。确切豆瓣作品链接可按需读取空缺资料，失败暂停、支持停止和重试，不覆盖手填内容。
- **界面与整理**：中文／English 切换，离线随包字体；标签直接选择已有项或新建分配。音乐入口暂时撤下，历史数据仍保留。

## 开始使用与数据

完整解压 `Qiyu-NoInstall-0.4.36-x64.zip`，保留所有文件。可先运行「启动演示.cmd」体验合成收藏；它使用独立目录。使用真实收藏前，请在原版导出完整备份并退出旧程序，再运行「栖域.exe」。

收藏仍为 `schemaVersion: 1`，启动不自动迁移或补写。新版包含旧版不了解的可选字段及外置截图；含截图时使用 `.roost` 完整备份，保留升级前备份，不用新旧程序交替编辑同一份收藏。详见 [数据兼容](https://github.com/kayins897/roost/blob/v0.4.36/DATA_COMPATIBILITY.md)。
