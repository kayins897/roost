# 0.4.32 · 书籍导入与卡片优化验收

本地独立候选，免安装，不替换正式发布。先完整解压并运行「启动演示.cmd」，只操作演示数据。
正常 EXE 沿用原数据目录；正式使用前请在原版本导出 .roost 完整备份，退出原程序再启动新版。

## 游戏卡片与评分

1. 筛选已体验→收官完结，右键一款已评分游戏。整数／小数滚轮各选一档，停顿并在两列间换焦点，封面应留在原评分段。按 Enter、Escape 或点击菜单外侧结束编辑，分数才最终保存并进入相应分段。没有额外保存按钮。
2. 清除评分也在菜单结束后生效。保存失败显示原位错误，菜单与草稿保留；处理冲突后使用「重试」或「撤销修改」，不会因另开快捷菜单而丢失草稿。
3. 卡片视图下只显示名称、时长和评分，0分、未评分及未记录时长有区别。五类二级筛选文字／圆点和封面边框应同色；平台等资料仍在详情内。
4. 设置→卡面材质：关闭应还原原图且保留悬停倾斜与状态边框；统一材质可选镭射或多彩。切到按评分区间，设最低／最高分和材质后应用；边界包含在内，重叠会报错并保留原规则，未评分和未覆盖区间显示原图。退出重启后偏好仍在。

## 书籍控件与批量收录

1. 进入书籍页，分类栏应只包裹六个按钮，没有延伸的长尾；「收录时间」应与筛选、排序方向同为圆角胶囊。
2. 点击筛选。左侧切换作者／出版社／两种评分／类型／两种来源；搜索当前候选，选中即筛选。书架不向下跳。清空、Escape、点击外侧均可关闭；390px 窗口浮层不出界。
3. 进入「批量收录」，应默认书籍。粘贴每行一本书的清单，先生成预览。库中已有、清单内重复项不可勾选；取消不会收录。
4. 展开「表格格式与模板」，下载 CSV。保持第一行中文表头，用真实书目替换示例行（删除不需要的示例）。Excel 另存 UTF-8 CSV，或复制含表头的表格作为 TSV 粘贴。
5. 在预览中检查作者、出版社、类型和出版年份。选中的新书可统一设置想读／在读／已读（日期未记录）／闲置／弃读。初始为想读，导入不会覆盖库中书籍。
6. 保存后在「全部」查看新书，打开详情核对双评分、出版社、译者、ISBN、来源和标签。实际 0 分应保持 0。退出再启动后资料应保留。
7. 同一清单再次导入应全部跳过。切回游戏，收录中心→批量收录应仍默认 Steam 游戏。

## 表格格式

至少有「书名」一列，支持单列表格，也支持每行一个名称的 TXT。

```csv
书名,作者,出版社,出版年份,标签,豆瓣链接,我的评分,阅读来源
合成示例,示例作者,示例出版社,2026,文学；旅行,,,纸质书
```

可选列：原名、译者、ISBN、简介、书籍类型、豆瓣评分、资料来源。评分 0–10，最多一位小数；空格不当作零分。标签和阅读来源用顿号、分号等分隔。含逗号或换行的单元格使用 CSV 双引号；单元格内双引号写成两个双引号。文件统一 UTF-8，最大 2MB、2000 本。未知列会提示但不导入，不从日期／时长等未知列推测阅读经历。

JSON 支持 {"books":[...]}、书籍数组以及 qiyu.batch.v1。书籍记录使用 title/name、creator/author、year、subcategory、tags、sourceUrl、personalScore，出版资料可写 bookDetails（也支持 publisher、translator、isbn 等平铺）。完整收藏备份仍在设置中恢复。

## 当前限制

- 这是一批书名／书目资料的收录，不是豆瓣或微信读书账号的自动抓取与同步。仅有书名不自动获取封面；豆瓣链接能规范化作品编号用于去重，但此入口不逐本联网补资料。
- 列表先收录到书架；主题书单沿用书架右侧的创建／编辑入口，不从一个文件自动创建多份主题书单。
- 去重沿用来源编号与保守同名／年份规则，ISBN 尚未作为独立去重键。同名但不同版本如被跳过，可单件核对后收录。
- 仅支持上述明确映射的资料，不把来源软件的原始阅读历史、书评或笔记默默转成栖域记录。
- 未运行真实账号网络导入测试；全部自动验证使用隔离合成数据。
