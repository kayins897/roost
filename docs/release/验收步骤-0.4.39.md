# 0.4.39 PC 影视卡片验收

完整解压后，双击「启动演示.cmd」打开隔离收藏。正式使用前，可在旧版导出完整备份并退出旧版，再启动新版。

1. 在电影或剧集详情检查海报、评分和片长。宽窗里评分跨两行，片长和发行卡在旁边叠放，演职员与来源各占一张卡。缩窄窗口时检查布局自动重排。
2. 分别右键片长、发行信息、演职员、来源与评分、作品简介卡。每次只显示对应资料的编辑项。电影的片长编辑只有时长；剧集可编辑单集片长和总集数。
3. 保存新简介并展开全文。确认个人评分、豆瓣评分、片长、其他资料和观看进度各自保留。
4. 验证用独立合成收藏。出现问题可退出新版，再用旧版打开升级前的备份副本。此版本没有数据迁移。

源码验收使用 `npm test`（299 项）、`npm run desktop:build` 和 `node scripts/verify-screens.cjs`。影视回归覆盖跨行布局、独立资料编辑、零值和历史字段保留，以及 1024 与 390 像素窄窗。交付目录的「截图」提供电影首屏、下方记录、窄窗与剧集实拍。
