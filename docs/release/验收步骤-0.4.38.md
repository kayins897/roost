# 0.4.38 PC 影视详情验收

可通过随包的「启动演示.cmd」打开隔离收藏。正式使用时，先在旧版导出完整备份并退出旧版，再完整解压并启动新版本。

1. 在影视的电影、番剧或连续剧里打开作品。宽窗口内海报在左，右侧依次显示个人评分、观看安排、片长和作品资料。缩窄窗口检查海报、评分和各卡片可读。
2. 在评分卡右键，或点击卡片上的笔形图标。滚动整数和小数，关闭评分后再检查大数字。看过的电影可补录多刷，剧集可编辑季集进度。
3. 检查封面、标签、印象和长文观后感可分别编辑。片长和实际观看日志分别记录，观看进度和看完轮次也各自保存。
4. 检查旧收藏与本机海报可直接读回。若要回退，退出新版后可用旧版打开升级前导出的备份副本。

源码验收使用独立目录和合成收藏。已通过 `npm test` 的 299 项检查、`npm run desktop:build` 和 `node scripts/verify-screens.cjs`。影视回归覆盖独立评分弹窗、封面替换、印象和长文、观影日志、重看与重启读回。交付目录的「截图」提供宽屏游戏与电影详情对照及窄窗预览。
