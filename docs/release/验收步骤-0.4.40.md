# 0.4.40 PC 书籍详情验收

完整解压后，双击「启动演示.cmd」，进入书籍板块并打开任意书籍。演示使用独立收藏。

1. 检查封面、书名、作者和阅读状态是否好读。缩窄窗口，确认标题能换行，封面保持原比例，资料卡随窗口重排。
2. 分别右键封面、出版信息、评分、来源和简介卡片，检查各自的编辑入口。个人评分与豆瓣评分可以分别修改。
3. 展开简介和长文读后感，尝试编辑一句话感想并重新打开详情。从主卡片记录阅读，再补录一次读完记录，检查累计时长与读完轮次各自更新。

使用正式收藏前，可在旧版导出完整备份并退出，再启动新版。本版沿用收藏格式 schemaVersion 1。需要回退时，用旧版打开升级前的备份副本。
