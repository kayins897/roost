# 栖域 PC 0.4.37 搜索收录候选

完整解压免安装包。先双击「启动演示.cmd」，可用独立的演示收藏检查搜索和收录。

1. 打开「书籍 → 搜索收录」，输入书名、作者或 ISBN。核对候选的作者、年份和来源，再点「加入想读」。
2. 在同一窗口继续搜索。已收录候选会显示「已收录」，同名候选可以进入核对。
3. 打开「影视 → 搜索收录」，输入片名并点「加入想看」。若来源限制详情读取，可点「仅用搜索结果收录」，保存基本资料和来源链接。按搜索结果收录时，界面会提示影视归类。
4. 关闭搜索窗口，在想读或想看列表查看新增作品。已有筛选可能遮住新作品，可切换到全部或清除筛选。

正式使用前，在原版本导出完整备份并退出原程序，再启动此包内的「栖域.exe」。它沿用本机收藏。需要回退时，用旧版打开升级前的备份副本。

源站实测《活着》和《星际穿越》各返回两个候选。《活着》详情返回作者和 ISBN，封面未取到。《星际穿越》详情受限，候选基本资料可用于收录。
