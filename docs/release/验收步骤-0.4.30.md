# 栖域 0.4.30 验收步骤

这是预发行候选，只提供免安装 ZIP，不做安装包。

## 一、启动

1. 解压 `Qiyu-NoInstall-0.4.30-x64.zip` 到任意空目录。
2. 直接运行 `栖域.exe`（会读写你的真实收藏），或运行 `启动演示.cmd` 用随包演示库另开一份数据。

## 二、卡面材质只剩两档

1. 进入游戏库，把有评分的作品分别设成 8.2、8.9、9.2、9.7。
2. 8.2 与 8.9 应显示原始封面，没有任何金属或彩虹覆盖。
3. 9.2 应显示镭射（方向光带），9.7 应显示多彩（光谱带）。
4. 打开「设置 → 卡面材质」，说明文字应为「9.0–9.4 镭射 · 9.5–10 多彩 · 其余使用原始封面」。
5. 把有字母评级 S、A、B 的作品评分清空，它们应回到原始封面，不再出现闪箔、烫金、烫银。

## 三、评分按十个区间分组

1. 在游戏库把筛选切到「已体验 → 收官完结」，排序选「评分」。
2. 列表应按「9–10 分」「8–8.9 分」「5–5.9 分」这样的区间分组，没有作品的区间不出现。
3. 不应再出现「9.8 分」这种单分数分组。
4. 同一区间内按真实评分从高到低排列，8.9 排在 8.2 前面。
5. 0 分作品在「0–0.9 分」区间；完全没有评分的作品仍在历史字母区间。
6. 打开「排序方向」切换为升序，区间从 0–0.9 排到 9–10，段内顺序不变。

## 四、段内顺序

1. 悬停某个封面，左上角出现上移／下移按钮。
2. 在 9–10 区间点一次「下移」，两件作品的顺序应立即交换并保存。
3. 刷新或重启应用，顺序保持。
4. 给其中一件改分（例如从 9.8 改成 8.2），它应立刻离开 9–10 区间、进入 8–8.9 区间，且其它区间的顺序不受影响。
5. 在有搜索或标签筛选的状态下调整顺序，清空筛选后同区间内未显示过的作品相对顺序不应被打乱。

## 五、数据与隐私

- 本轮没有新增字段、存储键或迁移，`schemaVersion` 仍为 1；旧版可以打开新库，但旧版不认识区间分组，只影响展示。
- 回退前请先用「数据与备份 → 导出」留一份完整备份。回退后不会自动降级或清理数据。

## 六、已知限制

- 独立预览 `design/ruic-card-preview/` 不随发行包分发，它是设计对照，不影响应用运行。
- 预览里的分层素材是程序化派生的，只能用来判断链路是否成立，不能代表真实分层源素材的效果上限。
- 旧的材质验收脚本仍按 0.4.24 的六档材质断言，未更新，请以本说明为准。
