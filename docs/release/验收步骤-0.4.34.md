# 栖域0.4.34 · 影视分类验收

本地Windows x64免安装候选，未发布。解压后先运行`启动演示.cmd`，再点Dock影视；该入口使用独立合成数据。测试与打包未访问真实收藏库。正常使用前在旧版本导出完整备份并退出旧进程，核对左下角0.4.34。

1. 在电影／番剧／连续剧间切换。电影二级只有想看、看过（另有全部汇总），剧集增加在看；只有电影页有主题片单，剧集内容占满可用宽度。
2. 电影右键或点开详情，分类选项中不应出现在看、搁置、弃看。记录两次看过，可分别留日期和感想；第一次的内容应仍保留。
3. 给看过电影安排想看，表示计划多刷；它仍能从看过找回。番剧／连续剧可记录季集，在看重看不丢历史；填写进度不自动完成整部作品。
4. 在番剧页点击收录番剧、批量收录，默认类型应为番剧；TXT可直接设在看。JSON显式电影／剧集类型不因当前页改变，电影不接受在看；混合清单会提示适用范围。
5. 多选几部作品后切一级类型，多选应退出，避免误改其他类型。试用筛选和封面／列表，缩小窗口检查无横向溢出。
6. 旧混合主题片单编辑只列电影，原剧集等不可见成员仍保留。旧搁置／弃看资料也保留，单纯浏览、修改导演不迁移分类。
7. 关闭演示再用同一入口启动，核对评分、感想、类型、观看记录仍存在。不要删除演示目录定位文件；想要新演示请重新解压至新目录。

本轮不包含同IP分季关联、追番提醒、账号片单同步或正式日历。季集仅为手动观看指针；片长不会当成实际观看时间。
