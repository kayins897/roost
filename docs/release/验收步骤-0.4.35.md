# 字体与双语界面 v0.4.35

本地免安装验收候选，未合main或发布。先使用随包启动演示。

1. Dock打开设置 → 语言与字体，切换English；游戏、Books和Screen及菜单应随之切换。
2. Modern sans、Literary serif、System font轮流选择，关闭设置后仍生效。退出重启后语言和字体应保留。
3. 中文作品标题、标签和感想保持原文。英文界面新增番剧，切回中文应仍归为番剧。
4. 音乐无Dock入口，新建和批量收录无音乐选项。旧音乐记录保留在完整备份中。
5. 390／768／1440宽度检查菜单、设置与详情；字体和语言变更不应造成收藏写入。

新增Noto Serif SC为SIL OFL 1.1，完整许可与来源位于随包LICENSES/fonts与源码public/fonts。免费字体仅指字体授权，不改变应用许可证。未知的外部平台原始报错及用户内容保持原文。
