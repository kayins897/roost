# v0.4.36 书籍与影视批量收录验收

先完整解压免安装包，运行「启动演示.cmd」。本次不替换旧交付；已有收藏启用前请从旧版导出 `.roost` 完整备份并退出旧程序。

1. 进入书籍或影视，Dock「收录作品 → 批量收录」。在「表格格式与模板」下载 CSV 模板；也可从电子表格复制含表头的 TSV。书籍与影视分别导入；混合板块继续用 `qiyu.batch.v1` JSON。
2. 输入名称、作者／导演、年份、豆瓣作品链接等已知资料，生成预览。确认错误行提示、库中重复及清单内重复；有效 ISBN-10／13 也会识别同一本书的改名和格式差异。ISBN 不同的版本可能仍触发现有保守同名规则，可单件确认收录。
3. 每行「修正」可改名称、作者／导演、年份、来源链接、类型、评分、标签等。点击「应用到预览」重算去重，不写收藏；「取消修正」丢弃本条修改。现有作品不会在此被覆盖。
4. 有确切豆瓣作品链接的所选新记录可「读取所选 N 件」，或逐行「读取资料」。仅补草稿空缺，不覆盖人工填写的名称、作者、评分（含零分）、渠道等。核对封面、作者、年份及类型；来源限制访问时队列暂停，可稍后逐条重试或直接保留离线资料。没有链接的名称不会触发在线搜索。
5. 读取期间可「停止读取」；当前请求结束后停止，不应用停止后的返回。关闭弹窗须明确放弃清单；重新打开不应收到旧请求结果。只有最终「导入选中的 N 件」会一次追加。
6. 影视表格可混合电影／连续剧／番剧，明确类型保留。未写类型时，成功读取的来源类型优先；仍无类型才采用「文本清单的影视类型」。电影片长和剧集集数不等同于你的实际观看时长或看过记录。初始观看安排由你明确选择。
7. 再次导入同一清单应无重复新增；原有评分、感想、标签、截图和体验经历应保持。重启演示确认资料持久化。中英文界面及窄窗口检查预览、修正区和按钮可读。

## 边界

本版不登录豆瓣／微信读书，不抓整份网页书单，不按书名猜测作品，不绕过验证码或访问限制。实时来源连通性受来源与网络影响；自动化验证使用合成来源响应，不能代替你在本机用真实公开链接确认联网结果。原有单件「检索与导入」继续可用，书籍现在也能携带出版社、译者、ISBN、简介及豆瓣公开评分。

无新收藏字段、无存储键变化、无启动迁移。回退时保留新版完整导出和升级前备份，不用旧程序与新版交替编辑同一份收藏。
