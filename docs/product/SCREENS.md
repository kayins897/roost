# 影视模块第一版

本轮依据：所有者确认电影、连续剧、番剧，并要求沿用游戏／书籍区布局后，明确授权开始实施。本文描述0.4.33候选实际规则，不扩展其他媒体状态模型。

- 六视图：全部、想看、在看、看过、搁置、弃看。在看作品以普通尺寸置顶；支持封面／列表视图。
- “想看／在看／搁置／弃看／未安排”表示当前观看安排；“看过”表示曾完整看过的历史事实。重看可同时出现在在看和看过中，计数不应相加作为总数。
- 旧status在读取时解释：want→想看、active→在看、paused→搁置、finished→看过且日期未知。启动与浏览不补写。普通completed日志不是完整看过的证据。
- 单件或批量显式标记看过可以建立日期未知的轮次，重看保留历史感想。新增轮次可结束或保留当前安排；编辑旧轮次不自动结束重看。
- 连续剧／番剧轻量记录看到第几季、集；不提供逐集打勾、分季作品自动拆分或追番更新推送。修改进度不自动标记整部看完。
- 个人评分0–10分，0.1步进，所有观看安排均可评分。豆瓣公共评分独立。右键评分在关闭菜单时提交，失败保留草稿，需显式重试或撤销。
- 片长／单集片长是客观资料，实际观看分钟来自独立日常日志。未知与0分别保留，不按片长、进度或看过轮次推算时长。
- 一句话印象80字，长文观后感默认折叠；每次看过也可留独立感想。看过日期允许未知、年／月／日；日常日志需月或日，新增入口默认今日且可改，不伪造历史看完日期。
- 标签支持选择已有、创建、分配、移除；同类标签可多选交集筛选。主题片单是独立集合，删片单不删作品；隐藏或回收记录不因片单／标签整理被修改。
- 筛选：类型、导演、年份、个人评分段、豆瓣评分段、观看来源、资料来源、喜欢。评分段沿用游戏的一分分段，未知单列；不是公共／私人评分混合筛选。
- 收录：手动、离线纯文本／JSON批量清单、既有单件豆瓣链接识别。豆瓣资料仅补空，不同步私人账号、评论或整套豆瓣片单；批量清单不是历史记录恢复入口。

全局日历与跨媒体时间轴仍为独立预览，本轮不将影视日志宣称为已接入日历。
