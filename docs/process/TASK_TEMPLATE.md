# 任务 / 测试 / 交接（单一记录模板）

> 复制到 `docs/tasks/<任务号>.md`。私密日志和个人路径另存本机，不隐去未验证项。

## 身份与授权

- 编号 / 标题 / 状态：
- 作者 / 非作者独立评审者 / 集成人：
- 批准依据：PRD/ADR/所有者决定及日期；未决事项：
- 目标与验收标准（输入/可观察结果）：
- 范围文件、共享接口、禁止修改模块：
- 依赖任务及已审查 SHA：

## 分支与成果

- base 分支 / 完整 base SHA：
- 任务分支 / 完整 HEAD SHA：
- worktree：公开记录用相对描述，私有绝对路径只留本机。
- 工作区是否干净：未提交文件、保存的补丁/提交及领取者。
- 已完成（对应验收条目）：
- 未完成（逐项，不使用“基本完成”）：
- 修改文件与行为：

## 验证与风险

- 环境 / 时间 / 被测 SHA 或明确的未提交差异：
- 命令 / 退出码 / 结果摘要 / 去敏证据入口：
- 范围：单测、GUI、源码构建、指定成品、mock、真实网络分别注明。
- 未验证项目及原因：
- 已知问题、复现步骤、影响与是否阻断：
- 数据：schema/字段/存储键；无变更也写明。
- 备份、旧库/未知字段、失败恢复及代码/数据回退边界：

## 交接与集成

- 下一位第一个具体操作与剩余步骤：
- 等待谁决定什么；不受影响可继续的任务：
- 独立评审结论 / 需修订项 / PR 或 diff 入口：
- 依赖顺序 / 主分支合并权限：
- 回退目标提交 / 数据与停止写入条件：
- 集成 SHA 与确认人：未合并写“待集成”，不填任务提交冒充。
- 发布：是否涉及及授权来源；无授权不发布，不自动制作安装器。
