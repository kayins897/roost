## 开始使用

**0.4.24 是本地待验收候选，尚未上传 Release。** 完整解压免安装 ZIP 后，可先双击“启动演示.cmd”体验合成收藏；同一入口保留修改，并可与原正式版并行。正常使用前请先备份并自行退出旧版，核对界面实际版本。

## 隐藏、回收与恢复

卡片右键或右上角“更多操作”可隐藏、移到回收站；详情也提供管理入口。隐藏保留全部记录并可在“已隐藏”中取消。移到回收站可恢复，只有回收站提供永久删除，删除前会再次确认。隐藏和删除都不自动改游玩状态。

回收站及永久删除的 Steam／豆瓣来源编号保留导入排除，后续批量导入和同步跳过；恢复作品会解除对应排除。隐藏仍参与去重、资料补全和可选时长同步，不重新收录。永久删除无法在界面撤销，可用之前导出的完整备份恢复。旧程序不理解这些新字段，回退前见 [兼容边界](./DATA_COMPATIBILITY.md)。本次验证不读写真实收藏。

## 游戏批量编辑

1. 点击“多选整理”，点选作品；搜索或筛选后可继续选择，已选对象保留。“全选当前结果”仅追加当前结果。
2. 底部可分别选择“改当前关系”“改通关进度”，或添加/移除标签、隐藏、移到回收站。一次只处理一种动作，避免误改另一维度。符合资格的集合可直接设置优先级或个人评级。
3. 在同一个窗口设置内容、查看将改变的数量与逐件差异，然后“应用到 N 款”。取消保留选择，保存失败保留输入，成功退出多选。标签管理也可创建或选已有标签，再选择要分配的作品。

批量编辑只更新游戏的明确状态／标签，时长、印象、体验历史、封面和未选作品保持原样。切换板块会退出选择模式；关闭批量编辑弹窗保留选择，退出选择模式清空选择。

“暂时搁置”表示当前停下、以后仍可能继续；“已放弃”表示已不再计划继续。两者都保留作品、已记录时长与个人内容，不会删除收藏。只执行标签批量修改时也保留已放弃状态；Steam资料和时长同步同样不会替用户改回游玩中。

## 批量收录（只新增）

点击顶栏“批量收录”，选择文件或粘贴清单。生成预览后检查重复项、勾选新增作品、选择初始状态，再确认一次追加。保存失败时保留当前文本与选择，可修正问题后重试；关闭窗口后的草稿恢复尚未提供。

支持三类输入：

| 输入 | 资料与用途 |
| --- | --- |
| 每行一个名称的 TXT | 先选择游戏、书籍、影视或音乐；影视默认电影。游戏文本用于 Steam 清单，可选填 `名称 | Steam商店链接 | 游玩分钟` |
| Steam 库 JSON | `response.games`、`games` 或数组；条目须有 `name`，可带 `appid` 与以分钟计的 `playtime_forever` |
| `qiyu.batch.v1` JSON | 同批可有四个板块，包含名称、原名、年份、创作者、来源编号、标签、本地封面及游戏平台／四类标签等基础资料；游戏可带 `playtimeMinutes` |

每次最多2 MB、2000件。损坏行有提示，有效行仍能预览。默认“待体验”，不会根据库存、时长或清单推测通关、观影日期、喜欢或个人印象。纯名称清单没有封面时使用文字封面，后续可检索资料或上传图片。完整字段和可复制例子见 [批量清单格式](./BATCH_IMPORT.md)。

0.4.6 中，通用清单的 `playtimeMinutes` 仅用于游戏，须为非负安全整数，单位为分钟。明确填写 `0` 会保留零分钟，未提供则保持未记录；其他板块不会生成游戏时长。

重复检查优先比较 Steam／豆瓣编号，其次同一板块的名称和年份。双方都有年份且不同时可分别收录；旧作品缺年份时保守跳过。重复项不会覆盖已有资料、状态、时长、印象、标签或体验记录；同名但确实不同的作品可单件确认收录。完整收藏备份在此入口会被拒绝，避免误当新增清单。

“批量收录”读取用户提供的离线清单，不自行刷新库存。“连接 Steam”是0.4.7新增的独立在线入口，见下文。本机游玩历史、许可缓存、封面缓存与在线库存是不同来源：历史和手动分类不能证明当前持有，许可快照也可能滞后；不能把主页统计数当作逐项完整清单。

历史授权操作（0.4.6／0.4.7）曾按用户授权从本机许可快照与游玩记录执行一次性真实收藏补全：新增与补缺的规模、逐项清单及导入记录属于用户私人数据，保留在本机私密备份，不在公开仓库记录。原个人内容、较高累计时长与未知扩展字段保留；独立原文备份及previous校验通过，Steam编号重复与歧义均为0，再次计划为0新增、0更新。

当时的许可快照可能滞后，来源划分不构成逐项在线库存核验；未匹配当时有效许可的历史条目全部保留。最终Dock与时长布局已完成成品验证，重开核对确认打开0.4.7前后收藏内容不变。

## 连接 Steam 与主动同步

在 Windows 的“游戏”作品库标题旁点击“连接 Steam”，也可从“数据与设置 → Steam 游戏库”进入，填写主页链接／SteamID64与自己的免费 Steam Web API Key。读取官方 GetOwnedGames 后先检查新增、补缺、未变化及歧义项，选择作品并补充可取得的封面与基础资料，确认后保存。不需要 Steam 密码；库存详情必须对接口调用可见。

已有作品按唯一确切 AppID 匹配，只补空缺开发商、年份、原名、封面和来源资料。时长更新可关闭，打开后仅补入明确值或提高累计分钟，保留较高个人值；个人名称、状态、印象、标签、喜欢、体验记录及未知扩展字段保持。不同来源编号仅同名不会自动合并，批内同名或交叉原名的新条目也会阻止自动新增；已分别确切绑定的同名作品仍可各自同步。

密钥可仅用于本次连接，明确选择后才在这台电脑以系统加密存储记住；无法加密时不保存明文。断开连接可清除密钥，收藏与导出不含密钥。网络、可见性、限流或单件资料失败会给出结果，不清空既有记录。当前为主动读取并预览确认的同步，不后台定时刷新或删除缺席作品；未配置真实密钥时，隔离验证不等同于真实账号在线验收。详细规则见 [批量与连接说明](./BATCH_IMPORT.md)。

## 单件资料检索

Windows 的“检索与导入”支持游戏名称搜索 Steam、Steam 商店 `/app/数字/` 链接，以及豆瓣图书／影视 `/subject/数字/` 链接。读取后先预览，再新建或确认补充已有作品，最后通过编辑器保存。

合并只补充空缺资料、平台和来源编号，保留已有名称、印象、状态、标签、喜欢与时长。只有主动点击读取或选择作品时才访问网站，不上传收藏库。网站超时、限流、验证或封面失败时明确提示，保留手动入口，不绕过验证。网页版预览不提供桌面进程的联网能力。

## 整理与记录

- 四板块收藏支持新增、编辑、移除、封面上传、喜欢、来源链接、个人印象、搜索、排序和网格／列表切换。
- 游戏支持多平台、六种游玩状态与累计分钟；玩法、题材、游玩场景、其他四组标签默认直接展示，可查找和组合筛选。其他板块同样有直接标签筛选，独立状态语义仍待设计。
- 高级筛选提供平台／子类型与只看喜欢，可与搜索、状态和标签组合。标签管理限定板块和游戏分组，同名标签不会误改其他范围。
- 详情中可直接编辑时长与标签。印象在关闭详情、切换作品或进入编辑前先保存，冲突或失败时保留当前草稿与界面。
- 体验记录支持开始、进展、完成、随记，允许具体日期或只记到月份，可增改删。在作品详情中查看真实记录；收录时间不会代替体验日期，未记录不代表未体验。
- 单次记录中的时长不自动累加到作品总时长，避免重复计算。作品详情中的记录可以展开查看；暂撤总览页面和月份热图，已有记录完整保留。

## 备份、旧版与恢复

“批量收录”只新增；“数据与设置 → 导入收藏备份”会**替换整库**。后者用于旧网页版迁移或恢复：先在原网页地址导出 JSON，再到桌面版导入，核对后保留一份异地备份。不会自动读取其他浏览器的收藏。

桌面数据保存在 `%APPDATA%\QIYU`，可由设置打开目录：

| 文件 | 用途 |
| --- | --- |
| `library.json` | 当前收藏与本地封面 |
| `library.previous.json` | 上一次成功修改前的有效收藏 |
| `backups/daily-YYYY-MM-DD.json` | 当天首次修改前的有效收藏，保留最近7份 |
| `backups/before-import-*.json` | 整库替换／恢复前的原文；普通批量追加不额外生成此档案 |

每次保存有结构和修订检查、同目录临时文件及原子替换。外部修改、损坏或超限时停止普通保存，避免覆盖；通过显式导入有效备份恢复，原坏文件保留。收藏文件保存上限100 MB，整库导入读取上限128 MB。

浏览器开发预览使用独立本地存储。批量追加或整库导入前把原文写入 `qiyu.library.before-import`，空间不足则不写主库；此副本只有一个槽位。桌面与浏览器自动备份都在同一设备，不能替代定期导出。卸载配置保留应用数据；删除免安装程序文件夹也不会删除收藏。

多平台、外部编号及体验记录仍为可选字段，编辑和导出保留未知扩展；日期精度不变。详见 [DATA_COMPATIBILITY.md](./DATA_COMPATIBILITY.md)。
