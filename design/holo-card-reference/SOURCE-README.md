# 卡面材质：参考与校准说明

本目录是独立设计示例，不是应用发行版。原 DeepSeek 示例已保留在本任务分支的基线提交 `4e7c804`，第一轮校准版为 `3bbfa61`。本轮通过实际视频画面及可见公式核对后调整，不再沿用“全部逐字复刻”的表述。

## 最新调整：纹理＋底色滤镜

所有者进一步明确：镭射重点是三角切面之间的差异，闪箔需要更丰富，纹理与滤镜应共同构成材质。当前版本据此更新：

- 镭射默认启用三角切面，各面拥有稳定的朝向和轻微色偏，随视角产生不同反射明暗；少量朝向光源的面捕获银白高光，其他面尽量保留底图。没有画网格线、网点或让三角位置随机闪动。关闭“三角切面”后变为平滑光面。
- 闪箔在细银白环/放射束之外，加入冷青与淡紫金属底色、宽幅明暗起伏和局部分段细环。细节随光变化，避免仅用几道大白圈覆盖底图。
- 新增独立“底色滤镜”控制。纹理强度65%、底色滤镜55%、流速35%；滤镜调整对比和局部色温，保护近黑与亮字。三种材质共用滤镜机制，多彩仍保留原有HSL宽色带。
- “查看原图”同时关闭两层；任一层可单独归零，二者都为零才完整还原。重置恢复以上默认值，减少动态/暂停/图片回退能力保持。

三角内部着色与朝向、滤镜、分段细纹均属于按用户反馈加入的校准层。原视频可见公式主要表现纹理，不能据画面确定完整原始材质结构；不把这些新增实现冒充原作者源码。

## 本轮修正

- **多彩**：原示例误用HSV，改回视频的HSL路径及其输入预处理，保留原图明暗。移除高频闭合彩虹圈，使用较低频、斜向宽色带；横向输入控制干涉相位，纵向输入参与色相偏移。
- **闪箔**：移除没有画面依据的人造彩虹着色；UV尺度从0.18恢复到接近完整卡片尺度，呈现更细的银白环和放射束。中心除法加保护；新增金属底色与局部细纹见上节。
- **镭射**：最终步骤确实要混回原图，不能把粉白中间结果当成成片。第一轮采用平滑光面，当前按用户反馈替换为三角面内色偏和反射；不再用描线mask实现镭射纹理。
- 底图去除旧示例的竖条干扰，使用含亮、暗、彩色主体及文字的原创合成图。可用同一张本地封面对照三种材质，图片不上传、不写入收藏。
- 默认纹理65%、滤镜55%、流速35%，可查看原图、暂停、换图、恢复默认。两轴指针与方向键驱动反光，倾斜有缓动；减少动态效果时不自动流动也不倾斜。

## 哪些仍是校准值

视频没有给出完整工程，以下不能当作原作者确定参数：

- UV完整定义、色彩空间、uniform生成和时间单位。
- 闪箔最终着色；本版银白混合、动态范围压缩是依据成片的近似实现。
- 干涉场空间尺度、场心偏移、旋转与时间缩放。本版多彩使用旋转后的60×90场及(-60,300)偏移，避免密集闭合光圈；这些是调校值。
- 各材质最终覆盖强度。本页共同强度还会乘各自的混合响应，百分比不是视频的delta。
- 镭射三角面着色/朝向/银光、平滑光面的对角包络、滤镜调色与其纵向指针响应均为定制取舍，不是原视频中的完整公式。

因此本版是“参考校准”，不是原游戏shader或原作者完整实现的等价移植。素材不同会明显改变观感：多彩会改变彩色主体本身的色相，银白纹在深底更显眼。参考中本身存在的环形纹理不等同于此前要求去掉的网点/网格。

## 运行及边界

双击 `index.html` 即可，脚本为普通本地文件，无构建或联网要求。需浏览器支持WebGL；不可用/上下文丢失时保留静态原图，恢复后重建材质。隐藏页面暂停帧循环，流速/强度为零或查看原图时不持续渲染。系统减少动态效果下仍可直接调整强度/图片/方向键。

文件分工：`shaders.js` 仅材质公式，`fixtures.js` 仅合成底图与等比留边，`holo.js` 管渲染/交互，`holo.css` 管独立页样式。三个WebGL上下文仅限三联参考页，不代表正式应用逐卡挂载方案。

验证：运行 `node scripts/verify-holo-reference.cjs`；当前结果及具体覆盖见 `evidence/holo-reference-facets/verification-report.json`，第一轮历史结果在 `evidence/holo-reference/`。没有进行应用构建、正式成品或真实收藏测试，因为本轮没有修改应用代码、数据结构或发行内容。
