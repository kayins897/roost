## 本轮修正

- **多彩**：原示例误用HSV，改回视频的HSL路径及其输入预处理，保留原图明暗。移除高频闭合彩虹圈，使用较低频、斜向宽色带；横向输入控制干涉相位，纵向输入参与色相偏移。
- **闪箔**：移除没有画面依据的人造彩虹着色；UV尺度从0.18恢复到接近完整卡片尺度，呈现更细的银白环和放射束。保留可见公式的组合关系，压低非纹理区域的整体泛白，中心除法加保护。
- **镭射**：最终步骤确实要混回原图，不能把粉白中间结果当成成片。降低覆盖、保留暗部；默认用平滑对角光照包络替代三角网格。原视频刻纹只在明确勾选时出现，默认没有网格/网点。
- 底图去除旧示例的竖条干扰，使用含亮、暗、彩色主体及文字的原创合成图。可用同一张本地封面对照三种材质，图片不上传、不写入收藏。
- 默认强度65%、流速35%，可查看原图、暂停、换图、恢复默认。两轴指针与方向键驱动反光，倾斜有缓动；减少动态效果时不自动流动也不倾斜。

## 哪些仍是校准值

视频没有给出完整工程，以下不能当作原作者确定参数：

- UV完整定义、色彩空间、uniform生成和时间单位。
- 闪箔最终着色；本版银白混合、动态范围压缩是依据成片的近似实现。
- 干涉场空间尺度、场心偏移、旋转与时间缩放。本版多彩使用旋转后的60×90场及(-60,300)偏移，避免密集闭合光圈；这些是调校值。
- 各材质最终覆盖强度。本页共同强度还会乘各自的混合响应，百分比不是视频的delta。
- 去掉镭射网格后的平滑对角包络、其纵向指针响应是定制取舍，不是原视频中的公式。

因此本版是“参考校准”，不是原游戏shader或原作者完整实现的等价移植。素材不同会明显改变观感：多彩会改变彩色主体本身的色相，银白纹在深底更显眼。参考中本身存在的环形纹理不等同于此前要求去掉的网点/网格。

## 运行及边界

双击 `index.html` 即可，脚本为普通本地文件，无构建或联网要求。需浏览器支持WebGL；不可用/上下文丢失时保留静态原图，恢复后重建材质。隐藏页面暂停帧循环，流速/强度为零或查看原图时不持续渲染。系统减少动态效果下仍可直接调整强度/图片/方向键。

文件分工：`shaders.js` 仅材质公式，`fixtures.js` 仅合成底图与等比留边，`holo.js` 管渲染/交互，`holo.css` 管独立页样式。三个WebGL上下文仅限三联参考页，不代表正式应用逐卡挂载方案。

验证：运行 `node scripts/verify-holo-reference.cjs`；结果及具体覆盖以本轮交付说明与 `evidence/holo-reference/verification-report.json` 为准。没有进行应用构建、正式成品或真实收藏测试，因为本轮没有修改应用代码、数据结构或发行内容。

## 素材与使用

默认插画由本页Canvas合成，不含视频/游戏画面；研究静帧仅用于比对。视频作者的公式转录与参考不等于获得其工程/素材的再发布许可。后续正式集成前应核对来源、许可和署名，不把视频或原游戏资源当作栖域自有资产发布。
