# 游戏详情 · Bento 小组件交互预览

这是设计预览，不是已经接入正式应用的截图功能。基于 0.4.27 候选 `621251049e037f0a4b68b07f06c5be89853534f2`，不修改 `src/`、`desktop/`、版本号、用户收藏或工程规约。

## 设计 brief

用户要在每款游戏的个人档案里快速查看/编辑体验，重新获得完整的作品资料卡片，并收集自己的截图。保留深色、圆角与非对称 Bento；封面和照片承担图像视觉。根据所有者对尺寸相近、配色沉闷的反馈，本版拉开横向、竖向和小块比例。进一步按所有者重点参考的最后一张图，使用蓝紫体验渐变、暖橘印象渐变、紫色足迹渐变和玫红完成次数纯色；资料、标签、时长、相册和测评采用黑/炭灰底，以不同描边强弱区分，仍能逐卡自定。移除整条标题栏，作品名称留在资料卡，关闭按钮独立悬浮；不增加装饰卡片。

依据 [StyleKit 的 Bento Grid 说明](https://www.stylekit.top/zh/styles/bento-grid)，采用独立模块、尺寸层级、统一间隙和响应式适配，呼应手机桌面小组件的使用方式。外部风格页只是参考；不替换项目字体、分类规则或设计语言。

宽屏使用实际四列 CSS Grid，统一16px间距、24px卡片圆角。沿用本地CSS，不引入Tailwind或运行时CDN；提供 `grid`、`gap-4`、`lg:grid-cols-4`、`col-span-*`、`row-span-*` 等对应类。默认：

- 左侧大封面跨两列三行，完整显示原图，与右侧高低不同的模块对应。
- 右上体验卡跨两列，中间两张1×1统计，右下作品资料跨两列。
- 作品资料包含名称、发行年份、收录日期、创作者；保留平台与来源入口。
- 下方印象横跨三列，足迹占一列并贯穿两行；再由两列截图卡和一列标签卡拼合，四组标签及编辑能力保留。
- 最底部测评为整行折叠条。默认组合包含1、2、3、4列宽度，尺寸变化来自实际内容和跨行比例，不使用旋转、错缝或不一致间距制造“随机感”。
- 暖橘印象使用深色文字，其余默认深色/彩色卡使用浅色文字。渐变的两个端点同时参与自动对比处理，自定颜色时仍适配正文、辅助文字、输入与选择控件，保留白底和中灰回归保护。
- 中窗为实际两列，封面跨三行，与右侧体验/时长/次数三卡对应；下部足迹跨两行，与右侧相册/标签对应。窄窗纵向阅读，两项统计并排；封面跟随原图自然比例，最高为视口62%或520px，以contain保留完整图像。所有断点保持16px间距。

## 小组件动效

- 鼠标悬停卡片时上浮4px、缩放至1.01，240ms ease-out过渡和柔和宽阴影；现有小图标独立放大至1.1并交换前景/底色。
- 实际按钮按下缩放至0.98，输入框和选择框使用200ms focus ring；不对输入/选择文字增加整卡按压。
- 整理布局、拖动和右键菜单打开时不抬升卡片，避免命中位置变化。减少动态效果时取消上浮、缩放和过渡，内容功能保留。
- 网格行高由CSS按内容自然展开，避免将悬停后的缩放尺寸反馈到JS测高。折叠测评仍是紧凑整行，不为了Bento形式额外增高。

## 右键调整与配色

右键封面图片或任一卡片，直接在浮动菜单中选择：

- 尺寸：紧凑/标准/加大，点选立即生效并关闭菜单；依内容限定两档或三档，不把任意宽高自由拖成无法阅读的表单。分段按钮明确突出唯一当前尺寸，矩形仅示意大小。
- 配色：八个色板，也可使用取色器或输入完整的 `#RRGGBB`。正文、辅助文字、分类选项和表单随底色调整对比；错误色值不会应用。
- 恢复当前卡的默认色，不改变尺寸、顺序、文字或其他卡片配色。
- 默认色同时带回该卡的默认渐变/描边。选其他颜色时改为纯色，避免旧渐变盖住新色值；本轮未增加复杂渐变编辑面板。
- 「调整布局」进入整理模式，「卡片与内容」直接打开显隐面板。普通浏览不显示编辑工具条；无常驻的顶部操作栏。

此操作参照所有者视频中的“右键菜单内选尺寸、立即变形与回流”，不是照搬视频应用。视频没有演示配色或拖动，这两项来自所有者的独立要求。

## 布局整理模式

右键菜单进入「调整布局」后，底部出现浮动工具胶囊：

- 通过拖动柄换位，或使用上移/下移按钮、拖动柄的方向键；普通浏览不启用拖动。
- 每卡选择允许的紧凑/标准/加大尺寸，统计和折叠测评仅提供适合其内容的两档。网格限定宽度，内容增加时高度自动扩展，不截断资料或表单。
- 「卡片与内容」控制十张卡片显示，也可单独隐藏资料字段和标签分组。隐藏只是展示偏好，不清空内容。
- 完成应用于当前预览；取消恢复进入编辑前的布局和配色；恢复默认复位顺序、尺寸、配色及显示，保留文字与图片。
- 编辑期间业务内容不可误点；退出后恢复原有编辑交互。窄窗自动适配，不覆盖宽屏档位。
- 按DOM顺序排列，不使用dense填洞，避免键盘与视觉阅读顺序分离；特殊尺寸组合可能保留少量栅格空位。
- 每卡可聚焦后按 Shift+F10 或菜单键打开设置；Escape 返回原卡片。全部隐藏后仍有「添加卡片」入口，关闭再重开也可通过键盘找回。

## 范围与真实能力

可以在预览里点选分类、改示例数据、输入印象、展开测评、编辑资料、添加足迹、多选本机图片作临时预览、打开大图、左右/键盘切换、编辑说明及移出相册。

**所有布局和内容修改只在页面内存中，刷新或关闭即消失。不会复制保存本机原图，不写入收藏。** 用户已确认的应用托管副本和单文件完整备份方向见 [截图接入设计](../../docs/tasks/DETAIL_GALLERY_DESIGN.md)。不要把预览当生产相册组件直接接入。

预览底部保留设计边界标记；正式产品不应保留“布局预览”等实现说明。

## 验证

验证入口包括常规原型、布局、卡片菜单，以及独立Bento动效专项。最终结果和实际截图在交付预览的 `screenshots/validation.json`、`widgets-validation.json`、`card-menu-validation.json`、`bento-motion-validation.json`。专项报告记录被测五个文件的 SHA-256；不要拿旧报告替代改动后的验证。独立测试工作树执行 `npm test` 212/212、`npm run build` 通过，均退出码0；业务源码与设计起点相同，这两项不证明新设计已经接入正式应用。未打包或发布。

本轮最终实际结果：常规6组、布局7组、菜单16组、独立Bento布局/动效12组，共41组通过；0页面错误、外网请求和LocalStorage写入。三档常规窗口为1440×1060、880×1000、390×844，菜单另覆盖390×360矮窗四角，动效检查覆盖320～1920窗口和实际过渡帧。14组布局实测，默认桌面9种真实宽高组合；106个正文/辅助/表单等对比样本最低4.5434，渐变按计算样式每1%采样，不宣称逐像素覆盖。渐变改为自定义纯色再恢复的回归通过。原生Electron、触屏长按、原生下拉展开项、正式持久化和完整备份未验证。

布局专项：`node design/detail-gallery/check-widgets.cjs <组装后的预览目录>`。浏览器层面的结果不替代Electron、触屏、图片持久化和备份验收。

菜单专项：`node design/detail-gallery/check-card-menu.cjs <组装后的预览目录>`。覆盖全部卡片右键和即时尺寸、预设/自定配色、浅色/中灰与悬停对比、键盘、菜单四角及矮窗、全隐藏恢复、取消/重置保留内容与零存储写入。

Bento动效专项：`node design/detail-gallery/check-bento-motion.cjs <组装后的预览目录>`，独立检查计算列数、默认跨行、统一间距/圆角、实际悬停过程与复位、图标/按压/focus、编辑和菜单位置稳定及减少动态效果。普通静态截图不能替代动效验证。

本版两轮独立截图审阅确认：错落尺寸、彩色/渐变/黑色与描边层次贴近所有者最新参考，中窗跨三行和窄窗自然封面改善；无视觉阻断。竖向足迹仍留有供记录增长的空间，不为填空增加装饰。前版白底/灰底对比和全隐藏找回回归保留；默认窄屏仍按同一DOM顺序阅读，可手动移动资料/印象等卡片。受限栅格不保证任意尺寸排列无空位。
