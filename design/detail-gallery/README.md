# 游戏详情与截图相册 · 可交互布局预览

这是设计预览，不是已经接入正式应用的截图功能。基于 0.4.27 候选 `621251049e037f0a4b68b07f06c5be89853534f2`，不修改 `src/`、`desktop/`、版本号、用户收藏或工程规约。

## 设计 brief

用户要在每款游戏的个人档案里快速查看/编辑体验，重新获得完整的作品资料卡片，并收集自己的截图。保留深色、圆角与非对称 Bento；封面和照片承担图像视觉，资料卡、体验卡使用中性的统一材质，状态使用克制的辅助色。去掉底部脱离网格的资料长列表和额外展开入口，不增加装饰卡片。

宽屏：

- 左侧大封面，完整显示原图。
- 中间体验卡，下方时长/次数两张统计卡。
- 右侧作品资料与标签组成一张大卡，默认常驻，可编辑。
- 下方一句话印象与紧凑足迹，横向截图卡，再到默认折叠测评。
- 中窗把资料放入第二行宽卡；窄窗改为自然纵向阅读，截图横向浏览。

## 范围与真实能力

可以在预览里点选分类、改示例数据、输入印象、展开测评、编辑资料、添加足迹、多选本机图片作临时预览、打开大图、左右/键盘切换、编辑说明及移出相册。

**所有修改只在页面内存中，刷新或关闭即消失。不会复制保存本机原图，不写入收藏。** 用户已确认的应用托管副本方案见 [截图接入设计](../../docs/tasks/DETAIL_GALLERY_DESIGN.md)。不要把预览当生产相册组件直接接入。

预览顶部保持清楚的边界标记；正式产品不应保留“布局预览”等实现说明。

## 素材与本地运行

- 图像使用《空洞骑士》公开 Steam 商店示例封面和截图，属于各自权利人，仅用于这次本地界面设计参照；不是用户截图，不随仓库跟踪或应用发布。
- 来源：https://store.steampowered.com/app/367520/Hollow_Knight/?l=schinese 。本地预览素材清单在 `assets/SOURCES.json`。
- `assets/` 不在本设计目录内跟踪。组装预览时放入 cover.jpg、shot-1.jpg 至 shot-4.jpg，以及应用既有的 InterVariable.woff2、NotoSansSC-VF.ttf 和字体许可。
- 本地交付把这些素材与 index.html、preview.css、preview.js 放在同一目录，双击 index.html 即可浏览，不需要安装软件或 API。
- 验证：`node design/detail-gallery/check-preview.cjs <组装后的预览目录>`；使用本机 Edge headless、loopback，产出截图与 validation.json。测试只针对原型，不替代 Electron/仓储验收。
