# 游戏详情 · Bento 小组件交互预览

这是设计预览，不是已经接入正式应用的截图功能。基于 0.4.27 候选 `621251049e037f0a4b68b07f06c5be89853534f2`，不修改 `src/`、`desktop/`、版本号、用户收藏或工程规约。

## 设计 brief

用户要在每款游戏的个人档案里快速查看/编辑体验，重新获得完整的作品资料卡片，并收集自己的截图。保留深色、圆角与非对称 Bento；封面和照片承担图像视觉。按所有者参考，以蓝紫评分、暖橘印象、紫色体验足迹渐变搭配玫红标签，资料、时长、平台、相册和测评采用黑/炭灰底，以不同描边强弱区分。完成次数与标签交换颜色后退出默认布局，仍可恢复，原记录保留。移除整条标题栏，作品名称留在资料卡，关闭按钮独立悬浮；不增加装饰卡片。

依据 [StyleKit 的 Bento Grid 说明](https://www.stylekit.top/zh/styles/bento-grid)，采用独立模块、尺寸层级、统一间隙和响应式适配，呼应手机桌面小组件的使用方式。外部风格页只是参考；不替换项目字体、分类规则或设计语言。

宽屏使用实际四列 CSS Grid，统一16px间距、24px卡片圆角。沿用本地CSS，不引入Tailwind或运行时CDN；提供 `grid`、`gap-4`、`lg:grid-cols-4`、`col-span-*`、`row-span-*` 等对应类。默认：

- 左侧大封面跨两列三行，完整显示原图，与右侧高低不同的模块对应。
- 右上通关评分卡跨两列，0～10的大号数字成为该卡中心；中间为1×1时长与平台，右下作品资料跨两列。
- 作品资料包含名称、发行年份、收录日期、创作者与来源入口；拥有平台单独拆卡，显示实际拥有的平台图标和名称。
- 游玩时长加“最后运行”，示例日期为合成资料；空值明确显示未记录，编辑时可清空。日期独立于时长、完成次数和足迹，不从它们推算。
- 下方印象横跨三列；体验分类、游玩优先级与足迹合并为一列跨两行卡片，形成从计划到记录的纵向阅读。两列截图卡和一列标签卡在其旁拼合，四组标签仍保留。
- 最底部测评为整行折叠条。默认组合包含1、2、3、4列宽度，尺寸变化来自实际内容和跨行比例，不使用旋转、错缝或不一致间距制造“随机感”。
- 暖橘印象使用深色文字，其余默认深色/彩色卡使用浅色文字。渐变的两个端点同时参与自动对比处理，自定颜色时仍适配正文、辅助文字、输入与选择控件，保留白底和中灰回归保护。
- 中窗为实际两列，封面跨三行，与右侧评分/时长/平台三卡对应；下部足迹跨两行，与右侧相册/标签对应。窄窗纵向阅读，时长与平台并排；封面跟随原图自然比例，最高为视口62%或520px，以contain保留完整图像。所有断点保持16px间距。

## 评分、计划与足迹

通关评价采用0～10分、0.5分步进，空值显示未评分，真实0分显示0.0。只对新游戏+与收官完结开放；切换其他分类只收起编辑资格，不删除原分数。游玩优先级仍沿用SSS／SS／S／A／B／C，仅新作开荒、游玩中、未完待续和新游戏+可设；只有新游戏+同时拥有两种设置。分类、优先级和体验足迹在同一张卡内；普通足迹不推算完成次数或最后运行。预览9.0为合成值，不是旧字母评级的自动换算。正式接入前需要单独确定旧评级兼容与备份设计，不改现有收藏。

## 逐卡右键内容编辑

正常卡面移除“编辑”和“添加”文字。右键或聚焦卡片后Shift+F10，首先展示本卡专用内容：评分卡改分数；体验足迹卡切分类、设优先级及记录/修改/移除足迹；时长卡改小时与最后运行；资料卡改四个字段；平台卡勾选平台；标签卡改四组标签；印象/测评卡改各自文字；封面卡可换临时图片或恢复；截图卡选择展示方式、封面截图或导入。印象及展开测评在普通浏览时为只读，右键编辑后保存；取消和Escape不提交文字草稿。分类、优先级、平台选项点击即更新当前预览。

尺寸、配色、卡片管理和整体整理收进“外观与布局”二级页，不与内容编辑挤在一起。二级页Escape回内容，内容页Escape关闭并回原卡；右键另一张卡重新进入其内容页。空白区域/全隐藏后的右键直接进入布局页，不沿用上次卡片内容。

## 截图展示

默认只展示一张选定截图，图片铺满卡片，标题/张数轻量叠在顶部；点击仍打开完整原图。右键可切单图、四宫格或九宫格，网格按实际图片排列，不足数量保留空格，超过一组可翻页。单图封面选择与照片添加顺序分离，大图仍可遍历全部照片；更换模式、说明、封面不会丢图或改原索引。大图中也可设为封面截图。图片仅作临时预览，不保存原图副本。

## 平台与次要信息

- 平台卡默认展示示例拥有的Steam和Switch；编辑时可即时勾选Steam、PlayStation、Switch、EA、Battle.net、Ubisoft、WeGame、Epic Games。提供品牌图形及文字，不把平台当作账号绑定或内容一级分类。
- 支持PS5、Origin、战网、育碧等别名的图标映射；同一平台去重，未知自定义名称保留文字和首字占位。空列表显示未记录，不自动填Steam。
- 完成次数卡默认隐藏，在右键“卡片与内容”中可找回；数字及编辑仍保留，不用普通体验足迹数量代替它。
- 平台图形为本地参考资料，见[来源与边界](PLATFORM_ICONS.md)。不依赖在线图标库或运行时CDN。

## 小组件动效

- 鼠标悬停卡片时上浮4px、缩放至1.01，240ms ease-out过渡和柔和宽阴影；现有小图标独立放大至1.1并交换前景/底色。
- 实际按钮按下缩放至0.98，输入框和选择框使用200ms focus ring；不对输入/选择文字增加整卡按压。
- 整理布局、拖动和右键菜单打开时不抬升卡片，避免命中位置变化。减少动态效果时取消上浮、缩放和过渡，内容功能保留。
- 网格行高由CSS按内容自然展开，避免将悬停后的缩放尺寸反馈到JS测高。折叠测评仍是紧凑整行，不为了Bento形式额外增高。

## 右键调整与配色

右键封面图片或任一卡片，先展示其内容编辑；进入“外观与布局”后可选择：

- 尺寸：紧凑/标准/加大，点选立即生效并关闭菜单；依内容限定两档或三档，不把任意宽高自由拖成无法阅读的表单。分段按钮明确突出唯一当前尺寸，矩形仅示意大小。
- 配色：八个色板，也可使用取色器或输入完整的 `#RRGGBB`。正文、辅助文字、分类选项和表单随底色调整对比；错误色值不会应用。
- 恢复当前卡的默认色，不改变尺寸、顺序、文字或其他卡片配色。
- 默认色同时带回该卡的默认渐变/描边。选其他颜色时改为纯色，避免旧渐变盖住新色值；本轮未增加复杂渐变编辑面板。
- 「调整布局」进入整理模式，「卡片与内容」直接打开显隐面板。普通浏览不显示编辑工具条；无常驻的顶部操作栏。

此操作参照所有者视频中的“右键菜单内选尺寸、立即变形与回流”，不是照搬视频应用。视频没有演示配色或拖动，这两项来自所有者的独立要求。

## 布局整理模式

右键菜单进入「调整布局」后，底部出现浮动工具胶囊：

- 通过拖动柄换位，或使用上移/下移按钮、拖动柄的方向键；普通浏览不启用拖动。
- 每卡选择允许的紧凑/标准/加大尺寸，统计和折叠测评仅提供适合其内容的两档。网格限定宽度，内容增加时高度自动扩展，不截断资料或表单。
- 「卡片与内容」控制十一张可用卡片，默认显示十张；也可单独隐藏资料字段和标签分组。隐藏只是展示偏好，不清空内容。
- 完成应用于当前预览；取消恢复进入编辑前的布局和配色；恢复默认复位顺序、尺寸、配色及显示，保留文字与图片。
- 编辑期间业务内容不可误点；退出后恢复原有编辑交互。窄窗自动适配，不覆盖宽屏档位。
- 按DOM顺序排列，不使用dense填洞，避免键盘与视觉阅读顺序分离；特殊尺寸组合可能保留少量栅格空位。
- 每卡可聚焦后按 Shift+F10 或菜单键打开设置；Escape 返回原卡片。全部隐藏后仍有「添加卡片」入口，关闭再重开也可通过键盘找回。

## 范围与真实能力

可以在预览里通过右键编辑分类/优先级/评分、改示例数据、写印象/测评、改资料、整理足迹；也可选本机图片作临时预览、打开大图、切换展示、编辑说明及移出相册。

**所有布局和内容修改只在页面内存中，刷新或关闭即消失。不会复制保存本机原图，不写入收藏。** 用户已确认的应用托管副本和单文件完整备份方向见 [截图接入设计](../../docs/tasks/DETAIL_GALLERY_DESIGN.md)。不要把预览当生产相册组件直接接入。

预览底部保留设计边界标记；正式产品不应保留“布局预览”等实现说明。

## 素材与本地运行

- 图像使用《空洞骑士》公开 Steam 商店示例封面和截图，属于各自权利人，仅用于这次本地界面设计参照；不是用户截图，不随仓库跟踪或应用发布。
- 来源：https://store.steampowered.com/app/367520/Hollow_Knight/?l=schinese 。本地预览素材清单在 `assets/SOURCES.json`。
- `assets/` 不在本设计目录内跟踪。组装预览时放入 cover.jpg、shot-1.jpg 至 shot-4.jpg，以及应用既有的 InterVariable.woff2、NotoSansSC-VF.ttf 和字体许可。
- 本地交付把这些素材与 index.html、preview.css、preview.js、card-content.js、card-menu.js、layout.js、platforms.js 放在同一目录，assets还需包含platform-icons.js。双击 index.html 即可浏览，不需要安装软件或 API。
- 上版动效交付附6秒 `交互演示.webm`；本版评分与足迹交付以实际默认、完整布局与响应式截图为准，不复制上版视频冒充新画面。
- 验证：`node design/detail-gallery/check-preview.cjs <组装后的预览目录>`；使用本机 Edge headless、loopback，产出截图与 validation.json。测试只针对原型，不替代 Electron/仓储验收。

原生Electron、触屏/长按、真实收藏读写、截图托管副本、完整备份及最后运行同步未接入或未验证。上版212单测/build通过属于历史正式业务基线，本轮只改设计原型/独立脚本及文档，未重跑不受影响的应用构建，未打包、合并main或发布。用户数据未访问，图片与日期为公开示例/合成夹具。
