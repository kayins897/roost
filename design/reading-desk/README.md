# 私人阅读桌 · 书籍独立预览

以所有者确认的两幅概念图为依据实现的 **HTML 交互原型，不是应用更新**。仅使用合成书目、原创 SVG 示意封面、示例感想与分钟记录。所有变更只在内存保留，刷新恢复，不连接账号、正式收藏或浏览器存储。

## 打开与构建

已有项目依赖时，在本分支仓库根目录执行：

```powershell
node design/reading-desk/build.cjs
node evidence/reading-desk-preview/serve.cjs 4190
```

打开 `http://127.0.0.1:4190/`。也可直接双击生成目录的 `index.html`，不需要网络或服务器。字体和许可证随页面带走。构建支持一个自定义输出目录参数。

## 可操作范围

- 阅读计划／阅读记录单面切换；在读置顶。
- 接下来读与阅读记录各自切换封面网格／横向列表，视图选择在本次页面内分别保留。
- **删除“开始阅读”按钮，也不替换成“标为在读”。** 没有电子书阅读器。本轮不新增前台在读状态操作。
- 点封面或书名看详情、历次读后感；调整计划、补录／编辑读后记录、登记每日分钟。
- 主题书单展示固定示例，可打开书单和书目；它与标签独立，不提供创建／删除／分配书单的正式能力。
- 标签词云依据当前搜索结果中的不同已读书目计数，不按重读次数加权；点标签筛选，再点或清除即可恢复。网格保留一句话感想，列表给感想更宽的空间。
- 阅读足迹是按实际分钟的年度热力表摘要，可展开后用方向键选日、查看／添加／修改／删除日记录。未知时长不当作零，明确零单独标识；读完不额外生成分钟。
- 全局搜索支持书名、作者、标签、计划理由与历次个人感想；“重置预览”只恢复合成示例。
- 左侧悬浮 Dock 是独立预览内的书籍、书单和说明入口；窄窗口移到底部，滚动区域结束于 Dock 上方。

## 验证

```powershell
node node_modules/typescript/bin/tsc -p design/reading-desk/tsconfig.json
node design/reading-desk/build.cjs
node design/reading-desk/verify-preview.cjs
```

隔离 Edge 验证包含 10 组真实界面检查及桌面／1000／768／390／360 像素截图。`READING_DESK_URL` 与 `READING_DESK_OUTPUT` 可覆盖入口及证据目录。另有共享原型 26 单测、应用基线 219 单测及应用构建；通过不代表正式书籍功能或持久化已完成。

## 边界与后续
