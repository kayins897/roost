# 书籍主题书单与热力表 · 独立交互预览

基于 v0.4.30，延续六视图书架与组合筛选，新增右侧主题书单和可折叠的常驻热力表。仅使用合成书目、原创 SVG 封面、示例感想和分钟记录；修改只保留在本次页面内，刷新恢复。**不是应用更新，不访问正式收藏。**

## 打开

```powershell
node design/reading-desk/build.cjs
node evidence/reading-desk-preview/serve.cjs 4190
```

访问 `http://127.0.0.1:4190/`，也可双击输出目录 `index.html`。字体与许可证均在本地，页面不依赖网络；构建可传入自定义输出目录。

## 当前交互

- 全部／想读／在读／已读／闲置／弃读，单选展示；全部每本只出现一次，在读置顶。想读仅表示尚待开始，在读有独立入口。六个视图各自记住封面网格／横向列表选择。
- 闲置表示暂不安排，弃读表示明确不再继续本次阅读；两者保留计划理由、历次感想、读完记录和分钟。恢复想读或在读由用户明确选择，改理由、补分钟均不会自动恢复。
- 已读依据读完历史，曾读完后再重读、闲置或弃读的书仍出现在已读。详情可即时改变当前安排；首次选已读进入现有读完表单，日期允许未知。已有读完记录时，选择已读不再新增记录；“记录读完”才登记新一轮。
- 六种书架顶部均保留大型年度阅读热力表，默认展开，点标题旁箭头折叠；收起保留标题、累计统计与登记入口。切换分类和筛选保持展开选择，刷新恢复展开。依据实际分钟着色，筛选书架不改变它；窄屏横向看全年，支持回到年初与键盘选日。
- 右侧主题书单展示名称、简介、数量和三张封面缩略图，点击打开既有完整书单。书单使用完整书库，不随书架筛选缩小；窄窗口移到书架下方。复用“城市与远方”和“理解世界”两个固定示例，尚无书单创建／编辑功能。
- 筛选面板提供作者、出版社、我的评分、豆瓣评分、书籍类型、阅读来源、资料来源。个人与豆瓣评分互不代替；阅读渠道与元资料提供方分开。同维度任选匹配，跨维度同时满足；未记录与真实 0 分分开。
- 标签栏继续使用多选交集；加号管理新增、分配、移除或确认删除；右键书籍直接编辑已有／新标签。标签计数受当前书架、搜索和资料筛选约束，但不受已选标签再次缩窄。
- 所有筛选与搜索可组合，条件在零结果、折叠面板及切换书架后保留。已选条件可逐项移除；清除资料筛选不清标签，空结果的“清除搜索与筛选”清掉全部条件并保留当前书架。
- 出版社、个人分、豆瓣分、来源均为合成演示；没有真实抓取、登录、导入或对接豆瓣／微信读书。主题书单仍为固定示例，不提供电子书阅读器。
