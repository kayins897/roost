# 时间轴回顾与阶段规划交互预览

基于应用 0.4.30 的独立设计预览，**不是应用更新**。游戏、书籍、影视、时长、感想和计划全部为合成样本；演示今天固定为 **2026-10-27**。只在内存中操作，刷新恢复；不读写真实收藏、账号或浏览器存储。

## 打开

已有项目依赖时，在仓库根目录运行：

```powershell
node design/reading-workspace/build.cjs
node evidence/reading-workspace-preview/serve.cjs 4187
```

打开 `http://127.0.0.1:4187/`。也可双击生成目录的 `index.html`，无需服务器或网络。字体及其许可证随预览复制。自定义目录：`node design/reading-workspace/build.cjs <输出绝对目录>`。

## 本次可操作内容

- 首页在“回顾／规划”间切换，一次展示一面；共享年／月／周、前后范围、今天、媒体和文字筛选。当前导航不展示音乐。
- 回顾采用垂直时间轴：桌面中轴交替卡片，窄窗单列；同日同作品聚合，可展开单条记录。月／年精度保持原样，无日期记录单列，不虚构日期。
- 游戏标签词云按**当前范围实际体验的游戏**统计，切换作品数量／已知时长及玩法／题材／游玩场景／其他。库存和计划不混入；点击标签看贡献作品。同一游戏同一标签只计一次，但多个标签各计该作品完整时长，不是时长占比。
- 规划不是任务清单。年按四季／月份，月按月初中末／自然周，周放候选作品；不要求全部完成。冬季明确指当年一二月与十二月；自然周可能跨月、跨年，一个月不强制四周。
- 宽泛候选不会自动落到更细的第一阶段。同一作品可以从季节细化至周，仍只有一个候选；已有说明、在读关系、历史体验保持。没有安排时间的候选另列。
- 每条候选可调整、移回未定时间、移出候选。只有明确登记体验才产生实际记录；范围切换不自动顺延，不把候选勾成已完成。
- 原有书籍预览保留：阅读计划／阅读记录单面切换、在读置顶、待读排序、同书多轮感想和重读计划、日级分钟热力表、登记／修改／删除阅读记录同步日历。
- 空时长和明确 0 分开；不从 Steam 累计时长还原日级时长。记录普通游戏体验默认“随记”，不会自动通关。

## 建议验收

1. 首页“回顾”切每周、上一周：游戏已知 **220 分钟**（另有未知时长），书籍明确 **0 分钟**，影视 **102 分钟**。回今天，本周书籍 **70 分钟**；月度游戏已知 **245 分钟**。
2. 词云切“数量／时长”、四组标签，点标签看作品；没有体验的库存专属标签不出现。切周、媒体后统计同步。
3. 切“规划”：月度查看月初中末与自然周，年度查看四季和月份。季节候选留在宽泛候选区，不会自动当作九月或月初计划。
4. 从某阶段加候选；在同一作品上继续调整到下一周。检查不会复制候选、增加体验时长或删除历史。
5. 点候选右上角菜单编辑，展开“管理这条候选”：移回未定时间或移出。取消、模拟失败、重试；失败草稿保留。
6. 书籍登记今天 30 分钟：热力表从 50 变 80，日历同步。修改旧感想不取消重读计划。
7. 调整至窄窗，内容可滚动至底部导航上方，弹窗不溢出；刷新全部恢复样本。

## 验证命令

```powershell
node node_modules/typescript/bin/tsc -p design/reading-workspace/tsconfig.json
node --test --experimental-strip-types design/reading-workspace/*.test.ts
node design/reading-workspace/build.cjs
node design/reading-workspace/verify-preview.cjs
```

原型单测 26 项；隔离 Edge 交互检查 16 组，输出 `evidence/reading-workspace-preview/verification.json` 和实际截图。通过 `READING_PREVIEW_URL`／`READING_PREVIEW_OUTPUT` 可指定验收入口及证据目录。脚本检查浏览器及 `file://` 入口，不启动 Electron。
